## التشغيل المحلي

المتطلبات: Node 22.23.2، pnpm 10.34.5، Docker مع Compose. من جذر المشروع:

```bash
pnpm install --frozen-lockfile
pnpm env:init
pnpm infra:up
pnpm dev
```

للتشغيل بالخلفية دون حجز الطرفية: `pnpm dev:start` (ينتظر الجاهزية ويطبع الروابط ثم يعيد السطر)، والإيقاف `pnpm dev:stop`. و`pnpm api:start`/`pnpm api:stop` لتشغيل الـAPI وحده (مع دعم `NODE_OPTIONS` أو وسائط بعد `--` مثل مهاد الساعة) وانتظار جهوزيته ثم إعادته للخلفية

الواجهة الافتراضية: http://127.0.0.1:5173/ . للإيقاف: `pnpm dev:stop` ثم `pnpm infra:stop`؛ لا تحذف volumes. إذا غابت إضافة Compose، استخدم `COMPOSE_BIN` وفق الدليل. بيانات `.env` المحلية مولدة وعشوائية ومستبعدة من Git والبصمات؛ لا تعرضها أو تنقلها.

التحقق: `pnpm check` ثم `pnpm test:distribution` ثم `pnpm test:integration --faults` و`pnpm test:containers`. اختبار الأعطال يوقف خدمات مشروع `hotel-phase1` مؤقتاً ثم يعيدها؛ لا تشغله أثناء استخدام البيئة لعمل آخر. `test:distribution` ينشئ قاعدتي اختبار محليتين ويحذفهما بعد النجاح.

لخفض إعادة الصياغة، نُسخ الملخص الأصلي حرفياً واستُخرج Word نصياً. ملفات docs تنظم القرارات والمواصفة السابقة بصورة مكثفة، وتكمل وثائق ما قبل التنفيذ بمسودات معلّمة. لا يُفترض أن التفاصيل الجديدة قرارات سابقة للمستخدم.
