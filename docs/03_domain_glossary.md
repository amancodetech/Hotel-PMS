# قاموس المجال والنموذج المفاهيمي

حالة: مواصفة مجال مقترحة؛ لا جداول أو مخطط فعلي هنا.

| المفهوم | تعريف ومثال | الملكية والعلاقات | دورة الحياة وطبيعة المعلومة |
|---|---|---|---|
| Tenant | العميل التجاري والأمني | المنصة تدير دورة العميل؛ يحتوي Properties وMemberships | إعداد/نشط/مقيد/إغلاق منظم؛ محفوظ |
| Property | نطاق تشغيل كمنتجع | Tenant واحد؛ مخزون ويوم عمل | إعداد/تشغيل/تعليق/أرشفة؛ محفوظ |
| Location | مبنى أو طابق | داخل Property، تنظيم مكاني | إنشاء/تعديل/تعطيل؛ محفوظ |
| Physical Resource | غرفة أو سرير أو موقع | داخل Property وله Location | إعداد/نشط/تقاعد؛ محفوظ |
| Accommodation Type | صنف خصائص كاستوديو | تعريف محلي وقوالب ممكنة | مسودة/نشط/متقاعد؛ محفوظ |
| Bookable Product | عرض كجناح A+B | يستخدم مورد أو مجموعة أو تركيب | مسودة/نشط/موقوف/متقاعد؛ محفوظ |
| Composition | الموارد التي يحتاجها العرض | نسخة مؤرخة داخل منشأة | تحقق/سريان/استبدال/تقاعد؛ محفوظ |
| Inventory Pool | موارد مؤهلة لطلب | عضوية داخل منشأة؛ ليست مخزوناً إضافياً | عضوية مؤرخة؛ التوفر مشتق |
| Inventory Commitment | التزام بضمان موارد لفترة | لحجز أو Hold أو مجموعة | مؤقت/مؤكد/مستخدم/محرر/مستوفى؛ محفوظ |
| Temporary Hold | التزام مؤقت بمهلة | داخل منشأة؛ قد يتحول لحجز | نشط/محوّل/محرر/منتهٍ؛ محفوظ بفعالية زمنية |
| Inventory Block | منع له سبب وفترة | مورد أو عرض أو نطاق تجاري | مسودة/مجدول/فعال/منتهٍ/ملغى؛ محفوظ |
| Reservation | الاتفاق الإجمالي | Property واحدة؛ نزلاء وبنود ودافعون | مبدئي/مؤكد/تنفيذ/انتهاء؛ محفوظ |
| Reservation Item | إقامة فرعية كغرفة مجموعة | تابع Reservation | حجز/وصول/إقامة/مغادرة/إلغاء؛ محفوظ |
| ReservationGuest | علاقة نزيل ببند وإقامة | داخل نفس Tenant وبصلاحيات Property | إضافة/تعديل/إنهاء؛ محفوظ |
| StaySegment | فترة بشروط ومكان متصلين | تابع Item ويربط السعر والتخصيص | مخطط/فعال/منتهٍ/مستبدل؛ محفوظ |
| RoomAssignment | تحديد المورد التشغيلي | Item/Segment؛ عدة موارد للمركب | مقترح/مثبت/مستخدم/منتهٍ/مستبدل؛ محفوظ |
| Occupancy | إشغال فعلي | من الدخول والخروج والتخصيص | مشتق، مع لقطات تقرير مؤرخة |
| Availability | إمكان قبول طلب فترة وكمية | من القيود والالتزامات والموارد | مشتق؛ لا يعدله موظف مباشرة |
| Readiness | إمكان التسليم الآن | من التنظيف والصيانة والفحص | مشتق من وقائع محفوظة |
| Package | استحقاقات كإفطار يومي | Property وقوالب محتملة | تعريف مؤرخ ونسخة حجز؛ محفوظ |
| Service Resource | موعد علاج أو مقعد رحلة | Property وسعة وزمن | إعداد/تشغيل/إغلاق؛ توفر مشتق |
| Owner | مالك أصل، لا صاحب Tenant تلقائياً | طرف وعلاقة مؤرخة داخل العميل | عقد/سريان/انتهاء؛ محفوظ |
| Operator | مشغل المنشأة | طرف وعلاقة تشغيل | تعاقد/تشغيل/انتهاء؛ محفوظ |
| Payer | نزيل أو شركة تتحمل رسوماً | طرف وتوجيه رسوم مصرح | اتفاق/تحمل/تسوية؛ محفوظ |
| Business Date | يوم العمل المفتوح | مستقل لكل Property | مفتوح/إغلاق/مغلق؛ محفوظ |
| Guest | شخص يقيم | سجل Tenant مع وصول مقيد | تعريف/تحديث/دمج مضبوط/احتفاظ؛ محفوظ |
| Group Allocation | حصة مجموعة قبل الأسماء | Property والتزام مضمون عند الحاجة | مبدئي/مضمون/مستهلك جزئياً/محرر؛ محفوظ |
| Conversation | سياق مراسلات ضيف عبر قناة مصرح بها | Tenant/Property وConnection؛ قد يرتبط بحجز أو طلب ضيف دون دمج الهوية تلقائياً | مفتوحة/معلقة/مغلقة/أعيد فتحها؛ محفوظة وفق سياسة الاحتفاظ |
| Message | رسالة واردة أو صادرة أو ملاحظة داخلية | Conversation واحدة؛ هوية خارجية ضمن Connection ونوع جمهور صريح | مستلمة/مطلوبة الإرسال/مرسلة/مؤكدة/فشلت؛ الملاحظة الداخلية لا ترسل خارجياً |

المورد ما يُستهلك حصرياً؛ العرض طريقة تقديمه. النوع وصف؛ Pool مجموعة مرشحين؛ الوحدة مورد معين. Location لا ينشئ اعتماد مخزون. الالتزام يضمن التنفيذ دون إعلان رقم غرفة. التخصيص يحدد مكان التسليم. سعة أربعة نزلاء لا تعني أربع وحدات. الإفطار استحقاق؛ الرحلة ذات المقاعد مورد محدود. الحجز عبر Properties يمثل مجموعة حجوزات مستقلة مرتبطة، وليس التزاماً غامض الملكية.

أصغر مورد يؤجّر مستقلاً هو أساس القياس: غرفة الفندق عادة مورد؛ أسرّة النُزل موارد؛ الفيلا المركبة عرض يستخدم غرفها. لا تحوّل كل أثاث إلى مخزون. المرافق المشتركة لا تستهلك حصرياً إلا بشرط صريح.
