   والمنافذ.

   وعدم كسر `runNightAudit` القائمة من P08-01 قبل استبدال مسارها داخل الحزمة نفسها.
3. **عند G-10**: جهّز حزمة الأدلة (تقرير تنفيذ + أرقام خام + أثر قاعدة البيانات + سجلات
   قتل/استئناف worker + بصريات شاشة اليوم)؛ **المراجعة المستقلة إلزامية قبل G-10** وفق
   docs/34، والبرومبت الجاهز [docs/75](75_phase10_review_prompt.md) والحكم في

4. **الحدود**: لا تُفتح P11 ولا أي بوابة أخرى؛ اعتماد P09 → P10 يتم بقرار المستخدم على G-09
