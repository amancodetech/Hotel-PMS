# التشغيل والأمان التشغيلي والتعافي

حالة: مواصفة ما قبل التنفيذ. أرقام الأداء والتعافي أهداف أولية مأخوذة من المرجع وليست نتائج قياس أو SLA موقعة.

## البيئات والبنية

Development/Testing/Staging/Production منفصلة الأسرار والبيانات. Docker/Reverse Proxy/TLS/PostgreSQL/Redis/Workers/Object Storage، مع تطبيق Stateless حيث يلزم. Redis ليس مصدر حقيقة مالية أو ضمان مخزون وحيد. لا استخدام بيانات ضيوف حقيقية للاختبار دون معالجة وضوابط محددة.

اختير Stack والهوية والتخزين ومسار النشر في docs/20_stack_repository_adr.md وفق D-12. الدفع اليدوي الموثق وFX المصادق عليه في D-11، وChannex هدف اتصال مشروط في D-19؛ المتطلبات الخارجية EX-01..05 موثقة في docs/27_readiness_gates.md؛ السعة والتكلفة وتوافر إصدارات الخدمات في Jakarta تتحقق قبل النشر.

## أهداف أولية

P95 للعمليات الشائعة 500–800ms وفق فئتها، والدخول/الخروج الأساسي ≤1.5s باستثناء المزود. حالات تحليل تركيب معقد تحتاج ميزانية وقت ونتيجة تعذر حسم؛ D-04 يحدد حدودها. توافر أولي 99.9% للطبقة القياسية، RPO≤15 دقيقة وRTO≤ساعة أهداف تتطلب ميزانية وبنية واختباراً.

## الرصد

Structured logs بمعرف طلب/عميل/منشأة وبدون أسرار. Metrics: latency/errors/DB/queue depth/oldest job/Unknown payments/hold expiry lag/inventory conflicts/channel lag/night audit/restore age. Traces عبر HTTP/DB/Workers بترابط. Audit مستقل عن Logs. التنبيه يحتاج مالكاً وعتبة وإجراءً، لا مجرد إشعار عام.

## النسخ والاستعادة

PITR ونسخ DB وملفات خاصة ومفاتيح الاستعادة مع تشفير وصلاحيات واحتفاظ محدد. اختبار استعادة كامل في بيئة معزولة مع قياس فقد البيانات والوقت. بعد restore: مطابقة المدفوعات والقنوات منذ نقطة الاستعادة، وضمان Idempotency قبل تشغيل الإرسال؛ عودة DB وحدها لا تعني أن العالم الخارجي عاد لنفس الوقت.

## مسارات تشغيل

- توقف Queue: العمليات الداخلية لا تفقد نية الإرسال؛ lag واضح، resume آمن.
- Unknown payment: لا retry تحصيل حتى مطابقة المرجع.
- فساد نشر: rollback التطبيق فقط إذا schema متوافق؛ migrations حساسة تحتاج forward fix أو استعادة مدروسة، لا down migration مدمرة تلقائياً.
- انقطاع شبكة الفندق: عرض آخر معلومات متاحة مع وقتها وفق سياسة؛ لا تأكيد مخزون عالمي Offline في V1 المعتمد. سجل يدوي للطوارئ ومطابقة عند العودة.
- تعطل مزود: استثناء وخطة خدمة بديلة؛ لا ادعاء نجاح وهمي.
- إغلاق يوم عالق: استئناف خطواته بالمرجع، لا إعادة جميع رسوم الليلة.

## CI/CD وهجرة العملاء

عند تفويض الكود: lint/static checks/domain/integration/isolation/concurrency/critical E2E ثم staging ثم بوابة نشر. migrations review وتجربة على نسخة آمنة. استيراد عميل: mapping وتجربة ومقارنة حجوزات مستقبلية وأرصدة ووحدات ثم cutoff ومنع إدخال مزدوج وخطة رجوع. عدّ السجلات وحده ليس مطابقة مالية.
