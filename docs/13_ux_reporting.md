# الواجهات والتقارير

حالة: مواصفة UX ومقاييس مقترحة؛ ليست واجهات منفذة أو تصميم صور.

## مسارات وشاشات

| الشاشة | القرار الأساسي للمستخدم | حالات مهمة |
|---|---|---|
| اختيار العميل والمنشأة | أين يعمل الآن | نطاق دائم ظاهر وعدم نقل السياق الصامت |
| Dashboard/Front Desk | وصول ومغادرة واستثناءات اليوم | يوم عمل وتوقيت منشأة واضحان |
| Calendar/Room Rack | الحجز والتخصيص | الكل والأجزاء وموانع التوفر بأسباب؛ لا لون واحد للحالة |
| بحث توفر | هل يمكن ضمان الإقامة | متاح/يتطلب نقل/غير متاح/تعذر الحسم؛ البحث لا يحجز |
| إنشاء/تعديل حجز | شروط ومبلغ والتزام | عداد Hold وفرق السعر وموافقة Split Stay |
| Check-In/Move/Out | جاهزية وإقامة وتسوية | تعارض أو نقص متطلبات؛ أفعال قابلة للتكرار بأمان |
| Folio/Payments | رسوم وتحميل دافع وتحصيل | Pending/Unknown لا زر تحصيل جديد مكرر |
| Housekeeping/Maintenance | المهمة وصلاحية التسليم | Dirty/Clean/Inspected وOOO/OOS واختلاف مستقل |
| Channel Dashboard | هل الحالة الخارجية متزامنة وهل البيع مفتوح | Open/Stop Sell حسب النطاق والفترة، التوفر المشتق، آخر إقرار/استثناء/Mapping ومالك معالجة |
| Unified Guest Inbox | ما الذي يحتاج رداً ومن المسؤول | مصدر القناة والحجز والمنشأة وحالة التسليم وSLA؛ الملاحظات الداخلية مميزة بوضوح |
| Reports | معنى الرقم ونطاقه | وحدة القياس والفترة والعملة وتاريخ التحديث |
| Settings/Admin | قدرات وأدوار وسياسات | أثر التغيير على حجوزات قائمة قبل الاعتماد |

دعم RTL/LTR كامل، keyboard/focus/labels/contrast، رسائل خطأ مفهومة، عدم الاعتماد على اللون وحده. لغة النص لا تغير القيم أو المنطقة الزمنية أو العملة. التأكيد الإضافي للأفعال الحساسة فقط؛ لا تكرار نوافذ لا تضيف قراراً.

صندوق المراسلات يعرض في سياق واحد المحادثة والحجز والنزيل والتواريخ والوحدة والحساب المسموح وطلبات الضيف، دون نسخ البيانات أو توسيع صلاحيات الموظف. تظل الميزة مخفية أو بحالة غير مدعومة قبل تفعيل CAP-17 للمنشأة والاتصال، ولا توحي الواجهة بأن الرد وصل ما لم توجد حالة تسليم مؤكدة.

## المقاييس

لغات الإطلاق ar وid-ID وen-US؛ IDR وUSD منفصلتان عن اختيار اللغة. شاشة الأدوار تعرض الصلاحية والنطاق ومصدر المنح والاعتمادات، وفق docs/09_identity_security.md؛ قواعد العرض والتحويل وتوقيت المنشأة في docs/21_indonesia_launch.md.

ليالي العرض ≠ ليالي الموارد المحجوزة ≠ ليالي الموارد المشغولة فعلياً ≠ عدد الأشخاص. فيلا 3 غرف لليلتين: 2 ليالي عرض و6 غرف محجوزة؛ لا تجمع 8. غرفة 6 أسرّة حصرية لشخصين: 6 موارد محجوزة و2 شخص. توزيع الإيراد على أجزاء تحليلي ومجموعه يساوي الأصل؛ لا تكرر الإيراد الأصلي في مجموع الأجزاء.

| التقرير | التعريف المطلوب قبل التنفيذ |
|---|---|
| Occupancy | numerator نوع إشغال محدد / مقام موارد مؤهلة لنفس النوع والفترة |
| ADR | إيراد إقامة مؤهل / ليالي مدفوعة مؤهلة وفق تعريف معتمد، معالجة الصفر معلنة |
| RevPAR | إيراد إقامة مؤهل / ليالي موارد متاحة بنفس أساس القياس |
| Revenue/Tax | posted events وتصحيحات حسب يوم العمل؛ لا الدفعات كإيراد تلقائي |
| Payments/Cashier | تحصيل واسترداد وعد فعلي وفروق ومطابقة |
| Arrivals/Departures | Items وحالتها الفعلية؛ لا إخفاء وصول جزئي |
| Pickup | تغير الحجوزات بين لقطة وتاريخ مرجعي محددين |
| Channel Performance | إجمالي وعمولة وصافي وإلغاءات، لا خلط سعر وصافي تحويل |
| Multi-Property | نطاق مصرح ووحدات متجانسة وعملة أصلية أو تحويل موثق |

سياسة OOO/OOS في المقامات محسومة في D-08 وdocs/23_v1_decisions.md. تعرض إقامات complimentary/owner منفصلة عن الإيراد، ولا يعد no-show إشغالاً فعلياً دون إقامة؛ لا تخلط مقاماً فيزيائياً بمقام تشغيلي. يبدأ Reporting من قاعدة التشغيل باستعلامات مضبوطة؛ Replica ثم Store عند الحاجة. يعرض lag للمصادر غير الفورية. تقارير مطابقة المال يجب أن تتوافق مع snapshot أو cutoff واضح، لا مقارنة أزمنة مختلفة كأنها عجز.
