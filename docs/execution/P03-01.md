# P03-01: المصادقة والجلسات (OIDC + جلسة خادمية)

الحالة: IMPLEMENTED / VERIFIED محلياً ضمن `pnpm test:identity` و`pnpm visual:phase3`. القبول النهائي ينتظر مراجعة G-03 المستقلة.

## النطاق المنفذ

- OIDC Authorization Code Flow مع PKCE (S256) عبر مكتبة `openid-client@6.8.8` مع Keycloak المحلي، وتحقّق من issuer وaudience والتوقيع والانتهاء وstate وnonce. سماح HTTP للمرجع المحلي فقط عبر `allowInsecureRequests`؛ إعدادات المشروع ترفض أي host غير loopback وأي NODE_ENV=production.
- مسارات `GET /api/v1/auth/login` و`GET /api/v1/auth/callback` و`GET /api/v1/auth/session` و`POST /api/v1/auth/logout`.
- جلسة خادمية في PostgreSQL (`auth_session`) ومعرف جلسة عشوائي 128-bit في cookie باسم `hotel_session` بخصائص HttpOnly وSameSite=Lax وPath=/ وSecure يُفعَّل عند الإنتاج (غير مسموح محلياً). تدوير الجلسة عند كل دخول: الجلسة الجديدة تسجل `rotated_from` وتُبطل السابقة.
- CSRF: توكن عشوائي يُخزَّن هاشه في الجلسة ويُسلَّم في cookie غير HttpOnly باسم `hotel_csrf` (double submit)؛ كل عملية مغيرة تتطلب `x-csrf-token` وOrigin ضمن قائمة الواجهة/API. غياب أو خطأ التوكن أو Origin = 403 قبل أي قرار عمل.
- تدفق OIDC في `auth_flow` (state/nonce/code_verifier) بصلاحية 10 دقائق واستخدام واحد فقط.
- MFA: تجهيز Realm بتدفق `browser-mfa` يضيف شرط الدور `hotel-mfa-required` إلى تدفق Conditional 2FA، ومخطط `oidc-amr-mapper` مع `default.reference.value` على تنفيذي كلمة المرور وOTP. الواجهة الخلفية تقرأ `amr` من ID token فقط (`otp`/`mfa`/...) ولا تثق بأي قيمة من المتصفح.
- تسجيل أمني منقح: `correlation_id` لكل طلب، `auth.login`/`auth.logout`/`auth.tenant_select` في `audit_event`، ولا tokens أو أسرار في responses أو logs.
- readiness: فحص identity يشمل health وOIDC discovery ومطابقة issuer. عند غياب discovery يفشل readiness بصدق.
- realm ومستخدمون اصطناعيون عبر `scripts/identity.mjs` بكلمات مرور من `.env` فقط، وOTP حتمي محلي عبر `KEYCLOAK_MFA_TOTP_KEY` — لا أسرار إنتاجية في المستودع.

## القيود

- `Secure` وcookie باسم `__Host-` لا يُختبران محلياً فوق HTTP؛ موثقان كإعداد إنتاجي.
- إبطال جلسة Keycloak نفسها عند logout يتم عبر end-session URL؛ فشل discovery يعيد تسجيل خروج محلياً فقط (موثق).
