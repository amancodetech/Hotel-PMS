## بصمات التسليم

`pnpm checksums` يعيد توليد `CHECKSUMS.sha256` بلا أسرار، ويستبعد لقطات قواعد الاختبار والمخرجات المولدة مع الإبقاء على اللقطة المرجعية للمهاجرات `.snapshot-hotel.json`. يُتحقق بـ`sha256sum -c CHECKSUMS.sha256`؛ أي تغيير غير مقصود بعد التجديد يظهر `FAILED`. أُعيد التوليد والتحقق بعد إصلاح R1..R6 وأُصلحت ملاحظة لقطات المراجعة وفق docs/37.

## ما أثبتته G-02

- عقد داخلي محايد عن المزود مع تحقق صارم يرفض provider/قناة مجهولين والبنية غير الصالحة دون تسريب قيم.
- UNKNOWN/PARTIAL ليست نجاحاً، و`PROVIDER_ACCEPTED` ليست `CHANNEL_VERIFIED`.
- حفظ revision الآمنة ونتيجتها أو استثناءها القابل للاستئناف قبل ACK؛ فشل commit لا يصدر ACK.
- منع التكرار: نفس revision ونفس hash بلا أثر جديد؛ نفس المفتاح بمحتوى مختلف يعزل في Exception دون الكتابة فوق الأصل.
- الترتيب: الأقدم لا يحيي ملغى؛ الغموض يذهب للمطابقة لا إلى إسقاط.
- Outbox حدث منطقي واحد، lease حصري بـ`FOR UPDATE SKIP LOCKED` وfencing token؛ نتائج العامل القديم لا تكتب فوق الأحدث.
- BullMQ قابل لإعادة البناء من PostgreSQL (فقد Redis → interval fallback وعمل مستمر).
- ACK بحجز دائم وتوكن وموعد استرداد، مع استثناء `ACK_EXHAUSTED` للمحاولات المهجورة وإعادة معالجة مصرح بها.
- يقين متحفظ: `NOT_SENT` فقط بدليل قبل الإرسال؛ invalid JSON/oversize/انقطاع غامض `UNKNOWN`، والوضع الافتراضي local-only يرفض المضيف الخارجي قبل الشبكة.
- تحذيرات ومراجع المزود لا تُحفظ كنص حر: أكواد آمنة فقط في `response_safe` وoutbox.
- retry محدود وbackoff حتمي وRetry-After وDLQ وإعادة بسبب وفاعل، وأخطاء التحضير الدائمة معزولة لا poison دائم.
- Channex adapter: allowlist/redirect/TLS/مهلة/حد حجم/تنقية بطاقة وPII، وتطبيع feed وcursor وهامش تواريخ مفردة.
- قابلية التوسع: قناة سادسة اصطناعية وAdapter بديل يمران نفس الـconformance دون تعديل النواة.

## ما لم تثبته ولا تدّعيه

- لا اتصال حي بأي قناة؛ لا credentials ولا حسابات؛ لا شهادة Channex (P13).
- قدرات القنوات الخمس كلها UNKNOWN/NOT_AUTHORIZED؛ أسئلة D-20 وEX-01 محفوظة ولم ترسل.
- لا RLS ولا فصل دور تشغيل ولا OIDC/MFA/CSRF (P03)؛ الاختبارات بدور bootstrap محلي.
- لا محرك حجوزات/مخزون/مال ولا شاشات تشغيل؛ لا Endpoint عام جديد.
- `inspectMappings`/`readProviderState`/`readChannelEvidence` في Channex تبقى UNSUPPORTED حتى إثبات endpoints، وsupersede لحالات inventory_version مؤجل إلى P05-06.
- AT-17..21 مغطاة كطبقة نقل وليست AT منتج نهائية؛ AT-C جميعها NOT_TESTED.

## البنية والتشغيل المحلي

- الجداول: 12 جدول `distribution_*` في قاعدة التطوير (tenant/property كأعمدة UUID بلا FK مؤقتاً وفق سجل التبعيات).
- الوحدات: `packages/backend/src/modules/distribution/{domain,application,persistence,adapters}` مع فحص معماري يمنع تسرب Adapter إلى النواة.
- العمال: `apps/worker` يشغل runtime اختيارياً عبر `DISTRIBUTION_WORKER=on` (افتراضياً off). الوضع المحلي يستخدم المحاكي فقط ولا يناسب الإنتاج.
- الواجهة: http://127.0.0.1:5173/ ؛ API 4100؛ Worker 4101. الإيقاف: `pnpm dev:stop` ثم `pnpm infra:stop`.
