# P02-06: Conformance suite وتقرير G-02

الحزمة / التاريخ / المنفذ: P02-06، 13 سبتمبر 2026، Asia/Makassar، نموذج التنفيذ المفوَّض.

الحالة: VERIFIED محلياً (طبقة النقل)؛ G-02 منفصلة عن G-03.

السلوك المنفذ وحدوده: حزمة conformance واحدة تفرض عقد المزود على كل Adapter: شكل revision عبر `parseChannelRevisionEnvelope`، شكل النتيجة عبر `parsePushResultEnvelope`، ack ضمن `certaintyLevels` ولا يعلن CHANNEL_VERIFIED، وMapping صالح أو رفض معلن. طُبقت على المحاكي (القنوات الخمس + قناة `test-sixth-channel` الاصطناعية)، وChannex adapter مقابل خادم محلي، وAdapter بديل في الاختبارات (`test-alternate`) لا يستورد Channex. اختبار معماري يفحص أن `domain` و`application` و`persistence` لا تستورد أي Adapter ولا تذكر Channex ولا تستورد بنية تحتية تشغيلية خارج persistence؛ `AdapterResolver` انتقل إلى Domain. اختبار تكاملي على PostgreSQL يشغل dispatcher وpull/ack عبر Adapter البديل. لا يعدل Domain المخزون/المال، ولا يسجل أي AT-C PASS.

المراجع: P02-06 في docs/32، docs/33 (إضافة قناة/Adapter)، AT-17..21 وAT-A06، G-02 في docs/27.
