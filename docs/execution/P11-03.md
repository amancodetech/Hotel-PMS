## السلوك المنفذ وحدوده

- شاشة `/properties/:propertyId/reports`: فلاتر (التقرير، الفترة، العملة، نوع المورد،
  التاريخ المرجعي، كل المنشآت/المجموعة) وعرض المقاييس بالوحدة والأساس والبسط والمقام،
  و`generated_at` وcutoff وحالة يوم العمل والتوقيت و`data_basis` وlag ظاهرة، ورفض الرقم
  `null` يظهر بسبب واضح (مثل `DENOMINATOR_ZERO`) لا صفراً مضللاً.
- تصدير خاص قصير العمر (CSV): `ExportReport` (منشأة) و`ExportTenantReport` (محفظة بعملة
  واحدة ونطاق مصرح مشتق خادمياً)، ينفذه عامل التقارير مرة واحدة (`report_export`)،
  صلاحية `report.export` (MFA) مفحوصة حياً عند الإنشاء/القائمة/التنزيل/الإبطال.
- الرابط/الملف ملك لعضوية المنشئ فقط: عميل آخر في نفس المنشأة أو مستأجر آخر يُرفض
  (404/403)، **ولا يُكشف response مخزّن لمن فقد العضوية/الصلاحية**، ويعمل بعد إبطال
  الجلسة عبر جلسة جديدة لنفس العضوية (الفحص بالعضوية والصلاحية لا بالجلسة).
- الانتهاء والإبطال: TTL = 15 دقيقة معلنة، والتنزيل بعد الانتهاء `410
  REPORT_EXPORT_EXPIRED`، وبعد الإبطال `410 REPORT_EXPORT_REVOKED`، ويُمسح المحتوى في
  الحالتين. الانتهاء الكسول يثبت حالته ثم يرمي الخطأ بعد commit (لا rollback يعيد التصدير).
- منع Spreadsheet Injection: كل خلية تبدأ بـ`=` `+` `-` `@` أو tab/CR تُسبق بفاصلة عليا
  قبل كتابة CSV، مع اقتباس الحقول التي تحوي فاصلة/اقتباس/سطر جديد. أُثبت بمحتوى عدائي
  `=EVIL("x")` مُدخل مباشرة في بيانات القناة.
- audit وcorrelation: `report.export_created` و`report.export_downloaded` و
  `report.export_revoked` مع `correlation_id`، وكل إنشاء idempotent (نفس المفتاح ونفس
  المحتوى يعيد نفسه، ومحتوى مختلف 409 `CONFLICT`).
- ثلاث لغات ar/id-ID/en-US مع RTL، و390px بلا فائض، والتصدير/الواجهة لا يعرضان PII.
