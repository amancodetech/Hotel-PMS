## فحص الكود

قورنت الملفات الفعلية بمصدر PSR-05 المقبول دون استعادة الأرشيف. راجعت الخدمة ومستهلكيها وحارس الإضافة والدفعات وأخطاء HTTP والعقد والترجمات:

- تحقق التاريخ يرفض التطبيع الصامت، والسنة صفر، واليوم غير الموجود؛ ويستخدم التخطيط لقطة `today` بحسب منطقة المنشأة. يعيد التنفيذ حساب اليوم بعد قفل المنشأة، مع بقاء replay بعد التفويض وقبل إعادة تقييم الطلب القديم.
- حارس التحويل يشمل VILLA/APARTMENT/HOUSE، ويقرأ المورد والأطفال ضمن tenant/property. الإضافة المباشرة ومعاينتها وبدء الدفعة وعرض خطوتها وتنفيذها تستخدم الحارس؛ قفل المنشأة ومعاملة الكتابة موجودان. البصمة القديمة أو المصطنعة قد تُرفض أولاً بـ412، ولا يعني ذلك تجاوز الحارس.
- المسار لا يعيد تكوين الذرات أو تعديل التزام قائم. رمز `INVENTORY_TRANSFORMATION_REQUIRED` هو422 في الخدمة والعقد، وله مفاتيح اللغات الثلاث. لا هجرة جديدة ولا تغيير حدود العزل أو النموذج المالي.
- تغيير توقيع `assertNotBackdated` له مستهلكان خدميان واختبار helper؛ بحث المستهلكين أكد تحديثها. تعديل provenance في اختبار SET يستعمل API لإنشاء نسخة مستقبلية ثم استبدالها عند بدايتها؛ لم يغير سلوك إعداد v1 لإرضاء الاختبار.
