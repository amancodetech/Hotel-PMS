## فحوص إضافية للثقة (ملاحظات docs/98)

1. **ذرية الاستيراد**: أعد إثبات أن الذرية تخص الصفوف المقبولة، وأن المرفوضة تُستبعد بالتصميم، وأن APPLY يرفض ملفاً بلا صف صالح.
2. **DRY_RUN**: لا ينشئ موارد لكنه يخزّن سجل idempotency؛ أعد إرسال نفس الملف بنفس المفتاح وطابق التقرير.
3. **الـpreflight**: تعارض أكواد، تجاوز الحد المباشر/سقف الموارد، وموقع مجهول تظهر قبل الكتابة.
4. **بصمة المعاينة**: أي حفظ مادي يبطلها (`412 PREVIEW_STALE`)؛ تأكد أنها تبقى صالحة بعد إعادة قراءة لا بعد كتابة.
5. **replay التنفيذ**: إعادة طلب ناجح بمفتاحه الأصلي تعيد النتيجة الأصلية حتى لو تغيرت المسودة لاحقاً (ليس خطأ نسخة).
6. **العقد**: `expires_at` غير موجود في استجابة المعاينة؛ لا توجد حقول تصميمية غير منفذة تُقدَّم كجاهزة؛ DORM/SUITE مرفوضان في العقد/السلوك.
7. **الواجهة**: الحفظ الجزئي الخادمي يعمل من المتصفح، وزر التنفيذ يظهر النتيجة والمهام، ورسائل الرفض لا تعرض بيانات مسودة قديمة.
8. **حد معلن**: واجهة استيراد الملفات ما زالت غير منفذة — أكّد أن البطاقة والعقد يصرّحان بذلك ولا تسجله عيباً جديداً.
9. **الانحدار العام**: شغّل الطقم الكامل والفحص والبصري؛ أي فشل خارج نطاق SET يسجل finding مستقلاً.

## معايير الحكم والتقرير

لكل finding سطر بحالة واحدة: **FIXED / PARTIAL / NOT_FIXED** مع الدليل والمسار، ثم حكم عام:

- **GO**: كل الحالات FIXED وتغلّب فحوص الإفشال، والأرقام المرجعية سليمة، ولا انحدار جديد. يُفتح SET-05.
- **GO_WITH_NOTES**: الحالات FIXED مع ملاحظات P2 غير حاجزة تُدرج كنتيجة متوسطة.
- **NO_GO**: أي PARTIAL/NOT_FIXED أو انحدار حاجز. تُعاد للإصلاح مع خطوات إعادة إنتاج دقيقة.

قالب `docs/execution/SET-R-reverification-report.md`:

1. الحكم والملخص (نطاق، ما شُغّل فعلاً، ما لم يُشغَّل).
2. جدول الحالات R01..R07 بالحالة والدليل.
3. النتائج الجديدة (ID، شدة P0..P2، مسار:سطر، إعادة إنتاج، أثر، إصلاح مقترح).
4. نتائج الفحوص الإضافية والانحدار والأرقام.
5. حدود الحكم (ما لم يُفحص، ما يعتمد على قراءة فقط، عدم قبول إنتاجي، SET-AT = NOT_TESTED، G-13 دون تغيير).
6. التوصية النهائية بفتح SET-05 أو إعادته للإصلاح.

## بعد الحكم

- عند **GO/GO_WITH_NOTES**: حدّث حالتي SET-03/SET-04 إلى VERIFIED_LOCAL (بعد الرجوع للخلف) أو ما يعتمد بمراجعتك، وحدّث [SET-progress](SET-progress.md)، ثم يبدأ SET-05 (الكامل/الأجزاء/الأسرة/الجناح) من بطاقته.
