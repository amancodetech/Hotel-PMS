- `Secure`/`__Host-` وTLS وrate limiting على edge: تحتاج نشراً حقيقياً (P13-02)؛ المشروع يرفض production محلياً.
- قبول قناة أو AT-C أو بيانات نزلاء حقيقية: خارج النطاق.
- SEC-006 (دعم مؤقت) وعمليات مالية/مخزون: مؤجلة بموجب سجل التبعيات.
- فحص تلقائي شامل على أجهزة حقيقية: غير متاح؛ الجوال محاكاة متصفح.
