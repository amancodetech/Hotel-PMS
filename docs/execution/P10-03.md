## السلوك المنفذ وحدوده

- **عقد Phase 10** (`docs/contracts/phase10.openapi.json`، 5 عمليات) مربوط بـ
  `contracts:generate`/`contracts:check`:
  - `GetNightAuditOverview` (GET `/night-audits`, `folio.read`): يوم العمل + التشغيل + الخطوات
    وcheckpoints + الاستثناءات + سجل التشغيل + `open_blocking` + `active_business_date`؛ يعرض
    آخر تشغيل مكتمل عندما لا يوجد تشغيل لليوم النشط.
  - `ListNightAuditRuns` (GET `/night-audits/runs`, `folio.read`).
  - `StartNightAudit` (POST `/night-audits/runs`, `business_day.close` MFA + CSRF +
    Idempotency-Key) ⇒ 202 تشغيل في الطابور ينفذه العامل.
  - `RetryNightAudit` (POST `/night-audits/runs/{runId}/retry`): يعيد إدراج الفاشل/فشل التحقق
    ويستأنف من أول checkpoint غير مكتمل؛ المكتمل يعيد نتيجته المخزنة.
  - `ResolveNightAuditException` (POST `/night-audits/exceptions/{exceptionId}/resolution`):
    تعليق بمسؤول وسبب.
  - `RunNightAudit` (P08) يبقى في عقد Phase 8 بنفس operationId مع استجابة موسّعة متوافقة.
- **الواجهة** `apps/web/src/night-audit/NightAuditPage.tsx` على المسار
  `/properties/:propertyId/night-audit` مع رابط في PropertiesPage والشريط الجانبي:
  تاريخ العمل/توقيت المنشأة/حالة اليوم، حالة التشغيل والخطوة الحالية وشريط تقدم
  `steps_done/steps_total`، جدول الخطوات وcheckpoints، جدول الاستثناءات (خطورة/حالة/مسؤول/سبب
  + زر تعليق مع حوار)، سجل التشغيل، أخطاء الخادم مترجمة (بما فيها تلميح BUSY القابل لإعادة
  المحاولة)، واستطلاع تلقائي كل 2s أثناء PENDING/RUNNING. ثلاث لغات ar/id-ID/en-US مع RTL
  و390px بلا فائض، وزر البداية يخضع لصلاحية `business_day.close` وسياسة MFA على الخادم.
- **سياسة التوقيت (AT-28)**: تاريخ العمل يتبع `property.timezone` لا ساعة الخادم؛
  `clockNow`/`HOTEL_CLOCK_NOW` مهاد محلي فقط (التهيئة ترفض production) واختبار وحدة عند حد
  منتصف الليل، والواجهة تعرض `business_date` و`timezone` صراحة.
- **البصريات** `scripts/phase10-visual.mjs` → `pnpm visual:phase10` (19/19 و8 لقطات):
  فتح الشاشة، 10 checkpoints، الإغلاق وظهور اليوم المغلق، استثناء الوصول المانع، التعليق
  بمسؤول وسبب، إعادة المحاولة بلا رسم ثانٍ، رفض owner-a بلا MFA، 390px وRTL.
- **حدود**: لا Computer Use في هذه البيئة (استثناء معلن مطابق P05..P09)؛ لا جهاز حقيقي ولا
  قارئ شاشة؛ لا قنوات ولا مزود.
