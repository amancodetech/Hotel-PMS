# مراجعة مستقلة لـPSR-02

راجع نطاق حفظ مسودات v2 والتوافق فقط، باستخدام docs/100 و101 وبطاقة PSR-02 ووثيقة PSR-02-contract. لا تعتبر إنشاء مخزون v2 أو شجرة المكان منفذين؛ عقودهما تصميمية لمراحل03/04. لا تقبل نتيجة المنفذ دون إعادة تحقق مناسبة.

## نقاط التحقيق

1. قارن SetupDraftInputV2 مع setup-v2.ts وcontroller والأنواع المولدة وعميل الويب. اختبر null/omitted/0 والمدخل الناقص والحقول الخادمية ونسخة غير مدعومة.
2. جرّب units معpattern، beds معcount، دورة مواقع، client_ref مفقود، تكرار أكواد عبر المجموعات، سياسة مشاركة غير مفروضة، ونمط متعارض مع القالب.
3. اختبر صلاحية قارئ، شركة أخرى، UUID موقع/مورد من منشأة أخرى، وفقد الصلاحية قبل replay. لا تتسرب البيانات ولا تحدث كتابة جزئية.
4. اختبر كاتبين بنفس ETag، الحذف وإعادة إنشاء الجيل، replay بعد تغيير الجيل، مفتاح بمحتوى مختلف، وترتيب مواقع مختلف بنفس display_order. يجب ألا يغير تطبيع hash ترتيب المدخل المحفوظ.
5. أكمل مسودة v1 ثم حاول Save/Discard/Apply بمفتاح جديد؛ كلها محمية. Apply بالمفتاح نفسه يعيد النتيجة الأصلية. لا يمكن ترقية المسودة المكتملة أو خفض إصدار v2 إلى v1.
6. تحقق من توقف المترجم عند BEDS متعدد الغرف، سعة تعتمد على default، SUITE بأكواد تحتاج حل مراجع، وسياسة مقيدة؛ لا اختلاق غرف أو UUID.
7. تحقق من رفض Preview/Apply/Readiness/تفعيل المنشأة لمسودةv2 حتى محرك PSR-04. لا تغييرات للمخزون أو الأسعار عند Save.
8. راجع تحديث fixtures للاختبارات الخمسة القديمة: الحصرية والأجنحة ومنع الأب كمرشح بقيت مختبرة، ولم يستخدم إلغاء حماية المكتمل كتجهيز.
9. افتح المعالج القديم بمسودة مكتملة ومسودة v2: رسالة واضحة بلا زر Save، معRTL والهاتف. النموذج الجديد ما زال نموذجاً غير موصول للحفظ حتى PSR-05.

## التحقق

شغّل build حديثاً قبل اختبارات PG. الطقم `psr-draft-v2` يستخدم قاعدة مؤقتة عبر test:property؛ اتبع بروتوكول إيقاف وإعادة خدمات التطوير. `pnpm check` يفحص العقود والأنواع والوحدات. `scripts/psr02-visual.mjs` اختبار واجهة مع GET مصطنع، وليس بديلاً لدليلHTTP/PG؛ لا تخلط مصدرَي الدليل.

اكتب PSR-02-independent-review.md بحكم GO/NEEDS_FIXES وfindings بمعرف PSR-Rxx وشدة ومسار ودليل إعادة الإنتاج. لا تغير D أو G-13 أو تعتبر المراجعة قبولاً إنتاجياً. سجّل ما لم يُختبر صراحة.
