## شروط تسليم البطاقة

1. كل مهمة لها دليل، وخريطة أثر docs/95 §5 مكتملة بـDONE أوN/A مبرر.
2. لا تعديل D/حدود العزل/المحاسبة أو الهجرات المطبقة، ولا تنفيذ امتداد مؤجل.
3. فشل تابع لمهمة سابقة يمنع إغلاق هذه البطاقة؛ لا mock لإخفاء API ناقص.
4. اختبارات التطبيق ليست مطلوبة لوثائق فقط؛ العقود والكود يحتاجان الفحوص الملائمة ثم check لإغلاق الكود.
5. الحالة النهائية لا تتجاوز الأدلة؛ ACCEPTED_LOCAL قرار المستخدم وفق سير العمل.
