# P06-02: تأكيد/تعديل/إلغاء مباشر بمعاملة واحدة

**الحالة:** IMPLEMENTED — الخلفية والعقد والاختبارات متحقق منها محلياً؛ واجهات التأكيد/التعديل/الإلغاء
مؤجلة إلى P06-06 (المسار الكامل). لا AT ولا قبول G-06.

## ما نُفذ

- **مهاجرة `20260915070000_reservation_confirmation`**: أعمدة `reservation.confirmed_at` و
  `reservation_item.confirmed_at/cancelled_at/cancellation_reason`، جدول `api_idempotency`
  (RLS/FORCE/trigger/منح أقل صلاحية، تفرد `tenant+operation+key`)، وصلاحيتا
  `reservation.modify`/`reservation.cancel` مربوطتان بـTENANT_OWNER/TENANT_ADMIN.
- **مهاجرة `20260915080000_stay_segment_update_grant`**: `grant update on stay_segment` لـhotel_api
  (لأن تعديل القطاع كان يرفض 42501).
- **`confirmReservation`**: تحقق نسخة المخزون (يقبل إزاحة انتهاء Hold واحدة)، تحقق quote سعر
  (منتج/فترة/كمية/بالغون/عدم انتهاء)، تخصيص ذري عبر `resolveAvailabilityForProduct`،
  `commitment` من نوع ITEM + `plan_allocation`، تحديث البنود `CONFIRMED` مع `price_snapshot_id`،
  اشتقاق الحالة الإجمالية، bump نسخة المخزون، Audit وOutbox `ReservationConfirmed` للمرتبط بقناة،
  وتخزين idempotency داخل المعاملة.
- **`modifyReservation`**: تحقق `version` (412)، replaces allocations تحت **نفس** الـcommitment
  (قيد تفرد `source_kind/source_id` يفرض التزاماً واحداً لكل بند)، إعادة التحقق من التوفر بعد تحرير
  القديم داخل المعاملة؛ أي فشل يلغي الكل ويحفظ القديم.
- **`cancelItem`**: نسخة البند، رفض الحالات المقيمة/الملغاة، `releaseCommitment` RELEASED
  وتحديث الحالة والسبب، bump النسخة، Audit وOutbox `ReservationCancelled`.
- **إعادة المحاولة idempotent**: نفس المفتاح ونفس المحتوى → نفس الاستجابة مع `replayed=true` دون
  أثر ثانٍ؛ نفس المفتاح بمحتوى مختلف → 409 `CONFLICT`.
- **العقد**: 3 عمليات جديدة في `phase6.openapi.json` (ConfirmReservation reservation.create،
  ModifyReservation reservation.modify، CancelItem reservation.cancel) + سكيماتها؛ المجموع 9.
- **إكمال تبعية P06-01 على القنوات**: `inbox-repository` و`external-booking-repository` يملآن
  `property_id` من الاتصال، وتهاجر 15060000 تتعامل مع قيود NOT VALID المؤجلة في قاعدة
  "legacy tenant" دون كسر العزل (بعد شهرين من الفحوص: identity 48/48 وdistribution 48/48).
