# P02-03: تخزين Inbox/Outbox/Attempts/Dedup على PostgreSQL

الحزمة / التاريخ / المنفذ: P02-03، 13 سبتمبر 2026، Asia/Makassar، نموذج التنفيذ المفوَّض.

الحالة: VERIFIED آلياً على PostgreSQL فعلي.

السلوك المنفذ وحدوده: migration واحدة تنشئ 12 جدولاً (connection, capability, mapping_version, external_booking, exception_case, inbox_revision, dedup_key, outbox_event, sync_attempt, sync_checkpoint, dead_letter + جدول MikroORM) بقيود حالتها وفهارسها، وrepositories خام معلنة فوق `em.execute` تحترم سياق المعاملة، و`storeChannelRevision` يطبق: حفظ revision قبل ACK، منع التكرار بنفس hash، عزل نفس المفتاح بمحتوى مختلف في Exception، كشف MAPPING_MISSING كاستثناء قابل للاستئناف، قرار ترتيب لا يحيي ملغى، وضمان نسخة واحدة للحدث المنطقي في Outbox مع lease و`FOR UPDATE SKIP LOCKED`. لا جداول حجوزات أو مالية ولا RLS (مؤجلة P03-03).

المراجع: DIST-001..004 وDIST-007، AT-17..21، P02-03 في docs/32، docs/25 (Inbox/Outbox/Idempotency/Exception)، docs/33 (الدوام والفشل).

الاعتمادات: P02-01 وP02-02 وG-01.

تغيير API / schema / permission / event: جداول جديدة فقط؛ لا تغيير OpenAPI.

Migration: تُطبق بـ`pnpm test:distribution` على قاعدة جديدة و`hotel_p02_legacy` بها جدول اصطناعي سابق؛ ثبت بقاء العلامة. `down` يزيل الجداول بترتيب عكسي. الترقية على بيانات اصطناعية آمنة؛ لا down في مسار الإنتاج. عند تطبيق `pnpm db:migrate` محلياً يُنشئ MikroORM لقطة `.snapshot-hotel.json` (مولدة، مستبعدة من Prettier) لازمة لإنتاج مهاجرات لاحقة بفروق صحيحة.

الاختبارات: `pnpm test:distribution` → نجاح الهجرات على قاعدتين، ثم 10/10 في 3 suites. أثبتت: تطبيق مرة واحدة وتكرار hash-identical بلا أثر، عزل revision بمحتوى مختلف دون الكتابة فوق الأصل، حفظ MAPPING_MISSING ثم الاستئناف بعد إضافة Mapping، ترتيب معكوس لا يحيي ملغى، crash قبل commit لا يترك أثراً (rollback فعلي)، crash بعد commit يبقي ACK PENDING قابلاً للاستئناف، تفرد حدث Outbox وlease حصري وانتهاء وretry، وتفرد محاولة لكل outbox+attempt_no. سبق الاختبار إثبات أن `em.execute` يشارك سياق المعاملة (`rollback→0` و`commit→1`) بعد أن أظهر `connection.execute` سلوك autocommit، فصححت طبقة SQL.

الأمن: لا أسرار ولا بيانات ضيوف؛ payload_safe هو envelope المطبع المنقى؛ الـexceptions تخزن مراجع وhashes لا محتوى حساس.
