# P02-01: العقد المستقل عن المزود ومصفوفة القدرات

الحزمة / التاريخ / المنفذ: P02-01، 13 سبتمبر 2026، Asia/Makassar، نموذج التنفيذ المفوَّض.

النسخة: بلا commit؛ بصمات الملفات المسجلة في `.local/verification/P02-01/hashes.txt` و`.local/verification/P02-01/report.json`.

الحالة: VERIFIED آلياً (طبقة نقل/عقد؛ لا شاشة فلا يلزم فحص بصري).

السلوك المنفذ وحدوده: عقد داخلي محايد عن المزود في `@hotel/contracts` (إصدار schema=1، certainty، رموز أخطاء آمنة، catalog للقنوات الخمس، أنواع القدرات وports)، وتحقق Zod صارم يرفض provider/قناة مجهولين والبنية غير الصالحة دون تسريب القيم، وتسجيل مزود ثابت `ProviderRegistry` يرفض المزود المجهول وتعارض المكرر وعدم تطابق إصدار Adapter. لا اتصالات شبكية ولا قاعدة بيانات ولا تنفيذ Adapter بعد. القناة السادسة الاصطناعية غير موجودة في كتالوج الإنتاج.

المراجع: CAP-13، DIST-001..004، D-19/D-20، P02-01 في docs/32، docs/33، AT-17..21 وAT-A06.

الاعتمادات والبوابات السابقة: G-01 مغلقة (docs/execution/P01-01.md)؛ لا اعتماد خارجي.

- `packages/backend/src/modules/distribution/domain/{certainty,errors,validation,ordering,capabilities,profiles,index}.ts`: سياسة التأكد والأخطاء، التحقق، قرار تطبيق revision، بوابات القدرات، ملفات القنوات الخمس.
- `packages/backend/src/modules/distribution/adapters/registry.ts`: registry ثابت.
- `packages/backend/src/modules/distribution/index.ts` و`packages/backend/src/index.ts`: تصدير namespace `distribution` دون كسر السطح الحالي.
- `eslint.config.mjs`: منع Domain الوحدات من استيراد Nest/MikroORM/express/Redis/BullMQ/persistence/application/adapters.
- `tests/distribution/{domain,contracts}.test.mjs`: 16 اختباراً.

تغيير API / schema / permission / event والمستهلكون المتأثرون: لا تغيير في `docs/contracts/v1.openapi.json` ولا operationId ولا schema نقل. ربط المنافذ بكتالوج العمليات الحالي:
