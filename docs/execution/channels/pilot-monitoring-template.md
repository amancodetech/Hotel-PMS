# قالب فترة مراقبة pilot (بلا بيانات حية)

الحالة: قالب تشغيلي محلي. لا يُملأ من محاكي، ويُستخدم عند تفويض pilot حقيقي (EX-02/EX-04).

## 1. تعريف النافذة (يُعتمد قبل الفتح)

| الحقل | القيمة |
|---|---|
| منشأة pilot والاتصال/الاتصالات | BLOCKED_EXTERNAL (EX-02) |
| بداية/نهاية النافذة وcutoff | يُعتمد مع مسؤول المنشأة |
| الموارد/الخطط المسموح نشرها | من قائمة Mapping المؤهلة فقط |
| مسؤول المناوبة والبديل | أسماء تُعيَّن في سجل التفعيل |
| عتبات التنبيه | lag، oldest pending، UNKNOWN، DLQ، استثناءات مفتوحة |
| شرط الإيقاف الفوري | فقد عزل/تعارض allocation/UNKNOWN غير محسوم/ادعاء قناة بلا دليل |

## 2. الإشارات والتصرف (من [docs/35](../../35_live_channels_runbook.md))

| الإشارة | القياس المحلي (P13-06 snapshot) | التصرف الأول | شرط الاستئناف |
|---|---|---|---|
| Outbox متأخر | `outbox_pending`، `oldest_pending_seconds` | منع زيادات النطاق المتأثر | حسم الطلبات العالقة وتسجيل النسخة |
| نقل غامض | `outbox_unknown`, `attempts_unknown` | مطابقة قبل أي زيادة | دليل حالة القناة أو إغلاق محافظ موثق |
| فشل دائم | `outbox_dead_letter` + open exceptions | مراجعة سبب ومسار إعادة معالجة مصرح | سبب محسوم واختبار سباق/عزل مستقل |
| Inbox غير معالج | `inbox_unprocessed` | تعيين مسؤول واستكمال المعالجة | صفر غير معالج مع سبب موثق |
| تجميد منصة | `active_platform_stops` | إبقاء الحصص محجوزة | رفع السبب عبر سياسة معلنة + مطابقة |
| lag ثلاثي | commit → provider acceptance → channel evidence | لا `CHANNEL_VERIFIED` قبل الدليل | عتبات معتمدة مسبقاً |

## 3. لقطات المراقبة المحلية

`node --env-file=.env scripts/p13-monitor-snapshot.mjs` (قراءة فقط) يكتب
`.local/verification/P13-06/monitor-snapshot.json`. اللقطة الحالية على بيانات تطوير اصطناعية
أثبتت الأعمدة: pending/unknown/dead/oldest/inbox/exceptions/freeze.

## 4. معايير الإغلاق والتوسيع

- كل إشارة أعلاه لها مالك مسمى وعتبة معتمدة قبل الفتح.
- التوسيع بعد نجاح الأدلة وتدريب الوردية، وبقرار مستخدم؛ لا يُغلق G-13 بغياب الشكاوى.
- مدة النافذة تُعتمد من المسؤول وفق حجم التشغيل، وليست رقماً مخترعاً.
