# P08-02: Folio/Charges/Payers والتوجيه والباقات والرسوم الدورية والودائع

التاريخ: 15 سبتمبر 2026. الحالة: **IMPLEMENTED / VERIFIED محلياً** (الأدلة أدناه). G-08 تبقى
REVIEW_PENDING؛ لا قبول بالنيابة.

## السلوك المنفذ وحدوده

- **Folio**: حساب لإقامة أو جهة دافعة (`GUEST/COMPANY/HOUSE/OWNER`) بعملة واحدة؛ فتح/قراءة
  وقائمة مع فلترة بالحجز أو الحالة؛ `GetFolio` يعيد الرسوم والتوجيهات والودائع والباقات
  والجداول والإجماليات المشتقة (`charges_total`, `routed_out/in`, `deposits_held/applied`,
  `balance_due`).
- **Charge**: ترحيل ذري لـJournal متوازن (مدين `FOLIO_GUEST`، دائن حساب الإيراد + `TAX_PAYABLE`)
  مع **لقطة ضريبة محفوظة** (`tax_policy` + `policy_snapshot_id` اختياري)؛ السجل المنشور
  immutable (لا update/delete لدور التشغيل) وتغيير سياسة الضريبة لاحقاً لا يمسّه (AT-F05،
  AT-R04). **مصادقة مصدر**: `UNIQUE (tenant, property, source_kind, source_ref)` وتكرار
  المصدر يرفض `SOURCE_ALREADY_POSTED` بلا قيد ثانٍ، فوق idempotency-key.
- **Payer routing**: توجيه رسوم إلى دافعين (حتى السداد) بقيود `AR_GUEST` مدين/`FOLIO_GUEST`
  دائن فقط، **بلا سطر إيراد ثانٍ** (AT-F08)، وtrigger مؤجل يمنع تجاوز مجموع التوجيه أصل
  الرسم؛ لا توجيه لنفس الحساب ولا لعملة مختلفة ولا خارج المنشأة.
- **الرسوم الدورية**: `charge_schedule` بمقاطع `DAY/WEEK/MONTH` وحدود `starts_on/ends_on`؛
  الترحيل متسلسل (`period_out_of_order` يرفض) والمصدر `schedule:{id}:{period}` فريد فلا
  يتضاعف الاستحقاق عند إعادة التشغيل (AT-F10)، والمصدر يُغلق الجدول (`STOPPED`) عند تجاوز
  النهاية.
- **الباقات**: `package_entitlement` بكمية وسعر وحدة، واستهلاك `package_consumption` بـ
  `UNIQUE (entitlement, source_kind, source_ref)` ومصدر الرسم `package:{id}:{ref}`؛ تكرار
  الاستهلاك يرفض (`duplicate_consumption`) ولا يضاعف الرسم (AT-O05)، وtrigger مؤجل يمنع
  تجاوز الكمية، وتصبح الباقة `EXHAUSTED` عند الاستهلاك الكامل.
- **الودائع/تأمين الأضرار**: تحصيل بالطرق `CASH/BANK_TRANSFER/EXTERNAL_POS` بمرجع خارجي
  ومصدر فريد → قيد `CASH/BANK/POS_CLEARING` مدين و`DEPOSIT_LIABILITY`/`DAMAGE_DEPOSIT_LIABILITY`
  دائن — **ليس إيراداً**. التطبيق على رسم بمبرر (`APPLY`) والتحرير بمبرر (`RELEASE` إلى
  `REFUND_CLEARING` بانتظار تسوية P08-03/04)، وtrigger مؤجل يمنع تجاوز المتبقي.
- **حدود**: الدفع/التحصيل النقدي والتحويل وPOS كتحصيل رسوم P08-03؛ الاسترداد/العكس/التسوية
  P08-04؛ الفاتورة/الصندوق P08-05؛ لا PAN/CVV ولا مزود دفع/FX ولا واجهة شاشة بعد.
