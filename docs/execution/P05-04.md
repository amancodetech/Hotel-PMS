# P05-04 الحجز المؤقت والحجب والصيانة

التاريخ: 14 سبتمبر 2026. الحالة: IMPLEMENTED / VERIFIED محلياً.

- `CreateHold`: قفل Property واحدة، إنفاذ انتهاء العهود المستحقة بوقت قاعدة البيانات داخل
  المعاملة حتى لو توقف العامل (INV-007)، تحقق `inventory_version` وإلا 412، تخصيص كل البنود
  أو لا شيء، ورفض تكرار المورد بين البنود.
- `ReleaseHold`/`ListHolds`: تحرير مرة واحدة؛ عقد منتهٍ يرفض 409 HOLD_EXPIRED؛ `ExpireDueHolds`
  يحرر التخصيصات ويزيد inventory_version.
- `CreateBlock`: مخطط يتعارض مع تخصيص قائم → 409 BLOCK_CONFLICT؛ طارئ يحفظ الالتزام وينشئ
  Disruption ويتطلب `maintenance.emergency`؛ `ReleaseBlock` بسبب موثق.
- `SetResourceMaintenance`: OOO/OOS دائم مع سبب؛ يتطلب `maintenance.emergency` لغير NONE.
- الأدلة: `inventory-api.pg.test.mjs` (انتهاء بلا عامل، حجب مخطط/طارئ، OOO)، و
  `inventory-constraints.pg.test.mjs` (قيود الاستبعاد)، و`inventory-scale.pg.test.mjs`
  (100 طلب متزامن: ضمانة واحدة فقط وأثر DB واحد).
