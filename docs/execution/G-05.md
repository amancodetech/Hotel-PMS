## ما أثبتته البوابة

- الضمان بPostgreSQL فقط: قيدا استبعاد GiST للتخصيصات النشطة ولحصص الحماية الفعالة، وقفل صف
  Property لكل كاتب، ورفض الكتابة بلا مسار الضمان، وانتهاء Hold بوقت قاعدة البيانات.
- 100 طلب متزامن على مورد واحد ينتج ضمانة واحدة وأثر DB واحد؛ لا overbooking داخلي.
- حصة القناة لا تُحرر بسحب مجهول أو HTTP 200؛ التحرير فقط بدليل مقبول بعد reconcile.
- أسعار Decimal(20,6) وHALF_UP عند الترحيل؛ كسور IDR لقناة غير مؤهلة ترفض بلا تقريب.
- عزل: RLS FORCE على كل الجداول الجديدة وأدوار تشغيل محدودة، و`hotel_api` يقرأ/يدرج Outbox
  فقط ولا يعدّله أو يحذفه.
