# P03-05: الواجهة وعقود API

الحالة: IMPLEMENTED / VERIFIED محلياً. القبول النهائي ينتظر مراجعة G-03 المستقلة.

## العقد والأنواع

- `docs/contracts/phase3.openapi.json`: 30 عملية منفذة فقط (جلسة، Tenants، عضويات، دعوات، أدوار، منح، صلاحيات، اعتمادات، تدقيق) مع `x-public`/`x-access`/`x-permission` و`x-csrf` لكل عملية مغيرة.
- `scripts/contracts.mjs` يتحقق من العقدين (V1 المخطط وPhase 3 المنفذ) ويولّد `packages/contracts/src/phase3.generated.ts`؛ `apps/api/src/identity/operations.ts` بيان مسارات مطابق، و`tests/identity/contract.test.mjs` يمنع الانحراف.
- لا endpoints وهمية: مسارات V1 المخططة غير المنفذة تعيد 404.

## الواجهة

- API client مركزي (`apps/web/src/api/client.ts`) مع CSRF من cookie، و`errorKey` لترجمة أكواد ثابتة.
- `AuthProvider` واحد: جلسة، عضوية نشطة، صلاحيات العرض، `selectTenant` (يمسح Query cache)، `signOut`.
- شاشات: `/login`, `/auth/callback`, `/select-tenant`, `/members` (أعضاء + دعوات)، `/roles` (أدوار/منح/اعتمادات + طلب اعتماد وإعادة محاولة)، `/audit`، وحالات منع/انتهاء جلسة. لا شاشات غرف/حجوزات/قنوات.
- الشريط العلوي: مستخدم/بريد، مؤشر MFA، مبدّل Tenant (يمسح الكاش ويحفظ السياق)، خروج.
- اللغات: ar (RTL) وid-ID وen-US مع حفظ التفضيل، ومبدّل لغة في الشريط العلوي يعمل من كل الشاشات المحمية. أسماء الأدوار النظامية والصلاحيات والأثر/النطاق وأحداث التدقيق وحقوله تترجم من مفاتيح ثابتة (`roles.*`, `permissions.*`, `auditAction.*`, `auditResource.*`, `auditField.*`, `errors.CODE`, ...)؛ رموز الأدوار/الصلاحيات تبقى معرفات تقنية معلنة (tooltip).
- التصميم: MUI الحالي، جداول مسؤولة قابلة للتمرير أفقياً داخل حاويات فقط، sidebar يلتف على الجوال، focus واضح، skip link، وأحجام 1440x900/1280x720/390x844/360x800.

## نتائج الفحص البصري (P03-06)

- دخول/خروج حقيقيان، اختيار Tenant، أعضاء، أدوار/منح/اعتمادات، تدقيق.
