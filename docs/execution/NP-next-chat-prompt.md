## النص الجاهز للمحادثة الجديدة

أريد متابعة صحيحة في دفعات قصيرة بنتيجة فعلية واضحة. **لا يوجد Webhook حتى الآن، ولا Callback HTTPS، ولا مستقبل محلي منفذ**. لا تسمّ اختبارات السحب أو إرسال STOP_SELL اختبار Webhook، ولا تستنتج منها أن فتح وإغلاق البيع تلقائياً من الحجز يعمل. لا تعد فحصاً ناجحاً للمصدر نفسه بلا سبب موثق، ولا تعِد طلباً خارجياً مجهول النتيجة.

ابدأ بتحديد النطاق الحالي والمتطلب الناقص من المصادر والأدلة، ثم جهز أول دفعة قابلة للمراجعة. إذا كان الهدف Webhook، يكون الترتيب: مستقبل محلي مقيد بنسخة الاختبار مع المصادقة واختبارات الرفض → مراجعة Astra → موجه HTTPS لا يعرض سوى المسار المحدد → Webhook غير نشط للمنشأة TEST Villa4 فقط → Test فعلي وقراءة نتيجته → التفعيل التجريبي إذا نجحت شروطه. لا تبدأ بمجرد نموذج Create Webhook أو URL افتراضي؛ لا يصل Channex إلى localhost مباشرة. أداة cloudflared موجودة، لكن المنفذ4200 والموجه والنفق لم يُجهزوا. عقود HMAC متعارضة وغير مثبتة؛ الترويسة السرية المخصصة موثقة رسمياً، ويجب وصفها كمصادقة مستقلة لا كتوقيع HMAC. لا ترسل أو تطبع أسراراً.

الغاية التشغيلية هي إثبات ما إذا كان الحجز يغلق البيع المتعارض، والإلغاء يعيد فتح المخزون المؤهل، فعلياً في Channex. **توليد ARI من تأكيد/تعديل/إلغاء الحجز المباشر غير منفذ حالياً**. قبل هذه التجربة ضع خطة محددة بالمعرفات والتواريخ والطلبات والقراءات المتوقعة، ثم أصلح الفجوة ضمن سياسة اختبار معزولة ومراجعة مستقلة. لا تفتح الفيلا وغرفها المتداخلة بالتزامن، ولا تتجاوز تعرضاً محمياً أو UNKNOWN لتنجح التجربة. Webhook يسرّع اكتشاف أحداث المزود، ولا ينفذ تحديث التوفر الناقص من حجز محلي تلقائياً.

بعد كل دفعة أعطني: ما نُفذ فعلاً، الدليل، ما لم يُختبر، والخطوة التالية. قل «غير منفذ» أو «فشل» عند تحقق ذلك. النجاح المحلي أو قبول المزود لا يعني وصول قناة OTA. إذا تعذرت الخطوة التالية بسبب متطلب محدد، احفظ نقطة استئناف وتوقف عندها بعد إنجاز العمل المستقل الممكن؛ لا تستمر في دورات فحص لا تحل المتطلب. لا تطلب تأكيداً للخطوات الروتينية المفوضة. قبل أي إتاحة خارجية، جهز النتيجة المقيدة والمراجعة أولاً واتبع التفويض الفعلي وحدود التنفيذ.

المنسق وحده يدير الخدمات والبناء وPostgreSQL والمتصفح والشبكة والأسرار. الوكلاء يعملون على المصدر والمراجعة ويرسلون أوامر التشغيل للمنسق. حافظ على ملفات الآخرين، وكل untracked، وdocs/86، والهجرة المطبقة، وExcel الأصلي. لا reset/clean أو إعادة استيراد أو تنظيف بيانات أو إنشاء شركة جديدة أو قناة حية أو شراء أو نشر إنتاجي أو تغيير D-20 أو قبول G-13 ذاتياً.
