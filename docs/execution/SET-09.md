## 0. حدود التفويض

- مسموح: دليل وتدريب وخطة pilot محلية ببيانات اصطناعية على قواعد معزولة.
- ممنوع بلا تفويض وبوابات: النشر، الشراء، القنوات الحية، إرسال رسائل، حذف بيانات مستخدم، تطبيق ترحيل مؤثر على قاعدة مستخدمة.
- G-13 وEX-01..05 لا تتغير؛ لا ادعاء جاهزية إنتاج أو قناة حية.

## 09.1 دليل مستخدم عربي مختصر

### المصطلحات

| المصطلح | المعنى في الواجهة |
| --- | --- |
| الشركة | الحساب وحد العزل |
| المنشأة | فندق/منتجع/مجمع له سياق تشغيل |
| تنظيم الموقع | مبانٍ ومناطق اختيارية |
| الوحدات | غرف/فلل/شقق/خيام/مواقع/أسرة قابلة للحجز |
| طريقة التأجير | حصرية، كاملة أو أجزاء، أسرة قابلة للبيع |
| فئة الإقامة | وحدات متكافئة في الوعود |
| الأسعار والشروط | خطط السعر والإلغاء ومدة الإقامة |

### المسارات المنفذة اليوم

1. **إضافة منشأة**: `/properties` → «منشأة جديدة» (اسم/رمز/توقيت/عملة/مجموعة) ثم تظهر بحالة SETUP.
2. **إعداد المنشأة**: `/properties/:id` بتبويبات: المواقع، الموارد، المنتجات (والمرشحون)، التركيبات، مسودات القنوات.
3. **فتح البيع**: صفحة الأسعار/التوفر `/properties/:id/rates` (خطط سعر وفترات وحصص).
4. **التشغيل**: المكتب الأمامي، المالية، التدبير، التدقيق الليلي، التقارير — كل مسار له شاشة وصلاحيات.
5. **معاينة المعالج (نموذج)**: `/setup-preview` نموذج مراجعة فقط لا يحفظ على الخادم؛ يوضح الرحلة البسيطة والمركبة، وطرق التأجير، ومعاينة الأرقام، ومحاكاة البيع، وحالات الحفظ/التعارض/الفشل.

### معنى طرق التأجير (كما في النموذج وما هو منفذ فعلاً)

| الطريقة | الوعد | الحالة اليوم |
| --- | --- | --- |
| حصرية | بيع الوحدة كاملة فقط | منفذة عبر مورد + منتج + تركيبة عند اللزوم |
| كاملة أو أجزاء | الكل يحجب الأجزاء والعكس | تقنياً عبر تركيبة + exposure؛ تجربة الإعداد لم تنفذ (SET-05) |
| أسرة | بيع سرير مع نطاق مشاركة | نوع BED موجود؛ نطاق المشاركة والبيع المنفصل لم ينفذا (SET-05) |

### حدود ورسائل يجب أن تظهر للمستخدم

- لا تأكيد مخزون دون اتصال؛ الحفظ الفاشل يظهر «تعذر الحفظ» مع إعادة محاولة.
- تعارض المسودة يظهر مقارنة ولا يفوز آخر حفظ بصمت.
- الجاهزية ليست فتح بيع ولا تفعيل قناة؛ كل منهما إجراء منفصل بصلاحياته.
- بيانات القنوات لا تعرض أسراراً؛ الربط الحي خارج التفويض.

### خطوات مستخدم نموذجية

- فندق صغير: منشأة SETUP → مواقع وموارد 101..116 (باستثناء 113) → منتج غرفة → مرشحون → تفعيل → خطة سعر وفترة → مكتب أمامي.
- فيلا كاملة: موارد غرف/أجزاء → منتج فيلا → تركيبة تفعّل → منع التداخل عند البيع.

## 09.2 تدريب اصطناعي

بيئة التدريب: dev محلي، مستخدمون اصطناعيون فقط، قواعد اختبار معزولة (`pnpm dev:stop` قبل أطقم PG)، لا بيانات ضيوف حقيقية، لا قنوات حية.

| # | السيناريو | الخطوات | النتيجة المتوقعة | الدليل |
| --- | --- | --- | --- | --- |
| T1 | فندق بسيط | معالج النموذج: غرف 101-116 باستثناء 113، حصرية، تأجيل السعر | معاينة 15 وحدة، نواقص لا تمنع المراجعة، محاكاة حصرية | لقطة شاشة + report.json |
| T2 | فيلا كاملة | فيلا 101-104، كاملة/أجزاء، إقرار خصوصية | محاكاة الكل تحجب كل الأجزاء | لقطة شاشة |
| T3 | رفض الخصوصية | اختيار كاملة/أجزاء بلا إقرار ثم متابعة | خطأ بجوار الخطوة ومنع متابعة | لقطة شاشة |
| T4 | أسرة | قالب DORM، عدد أسرة، نطاق مشاركة | عدّاد أسرّة منفصل؛ محاكاة سرير | لقطة شاشة |
| T5 | خيمة/موقع | قالب TENT/SITE | عدّاد مواقع منفصل | لقطة شاشة |
| T6 | تعارض مسودة | محاكاة تعارض ثم مقارنة | لا سحق صامت؛ خيارا الاحتفاظ/التحميل | لقطة شاشة |
| T7 | فشل حفظ | محاكاة انقطاع ثم إعادة | «تعذر الحفظ» ثم نجاح بعد الإعادة | لقطة شاشة |

## 09.3 خطة pilot محلية

- **النطاق**: منشأة اصطناعية واحدة على قاعدة معزولة، مستخدمون اصطناعيون بأدوار (مالك، استقبال، مشرف تشغيل، مدقق)، بيانات مولدة وليست حقيقية.
- **شرط الدخول**: SET-03..SET-08 منفذة ومتحقق منها محلياً + سجل SET-08 (جاهزية/أداء/لغات) + دليل SET-09 محدث بعدها.
- **الأنشطة**: دورة كاملة: إعداد → فتح بيع محلي → حجز → دخول/خروج → مالية → تدبير → تدقيق ليلي → تقارير؛ مع سيناريوهات رفض (تعارض، صلاحية، تكرار).
- **القياس**: إكمال المهام بلا مساعدة (هدف أولي 4/5 أدوار)، أخطاء منع/فشل مسجلة، زمن قراءة القوائم وفق حدود D-04، ومراجعة أثر كل تغيير إعداد.
- **معايير الخروج**: تصنيف SET-AT01..18 (PASS/FAIL/NOT_TESTED) بأدلة، وقائمة findings، وقرار مستخدم منفصل بالقبول؛ لا تحويل تلقائي.
- **شروط التوقف**: أي تسرب بين شركتين/منشأتين، أي مخزون مزدوج، أي نجاح واجهة بلا نجاح خادم، أي حاجة بيانات حقيقية أو فعل خارجي.
- **الرجوع**: استعادة/تصحيح موثق؛ لا إعادة قاعدة فوق نشاط لاحق؛ لا حذف بيانات.
- **البوابات**: أي قناة حية أو نشر أو شراء يبقى BLOCKED_EXTERNAL حتى EX-01..05 وقرار G-13، ولا يمنع نجاح pilot محلي من فتحها.

## 09.4 النشر التدريجي
