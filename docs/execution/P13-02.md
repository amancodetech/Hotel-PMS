# P13-02: فصل إعداد staging/production وفشل مغلق بلا أسرار + rehearsal استعادة محلي

الحالة: **IMPLEMENTED / VERIFIED محلياً** (10/10 اختبار إعداد، فحص الأمثلة يفشل مغلقاً، rehearsal استعادة PASS).
التاريخ: 17 سبتمبر 2026. المنفذ: جلسة P13 بتفويض محلي فقط؛ **لا موارد سحابية ولا أسرار حقيقية ولا نشر**.

## السلوك المنفذ وحدوده

- **ملف تعريف نشر صارم** `packages/backend/src/deployment/profile.ts` (fail-closed، غير موصول
  بـ`loadConfig` عمداً): يتحقق من TLS (https لWeb/OIDC/OTLP/التنبيهات، `sslmode=require+`
  لPostgres، `rediss://` لRedis)، منع loopback، أسرار بطول أدنى ومن مخزن أسرار
  (`aws-secrets-manager`/`vault` فقط)، فصل دور API عن العامل، `RLS_ENFORCEMENT=require-force`
  و`TENANT_CONTEXT_MODE=session`، سقف سجل بلا debug، نُهج مراقبة عامة، هدف نسخ `s3://` وجدول
  واحتفاظ ≥ 7 أيام وهدفا RPO/RTO، ومنع `simulator` عند `DISTRIBUTION_WORKER=on` مع لزوم
  `CHANNEL_LIVE_AUTHORIZATION_REF`، وفي production فقط `COST_APPROVAL_REF` و
  `PRODUCTION_AUTHORIZATION_REF` و`RESTORE_TEST_REF`.
- **مشغل الفحص** `scripts/production-config-check.mjs` يقرأ ملف env صراحةً (لا process.env
  مباشرة)، يطبع الحقول الحساسة منظّمة الطول فقط، ويخرج 1 عند أي مشكلة.
- **إعدادان مفصولان**: `infra/environments/staging.env.example` و`production.env.example`
  بقيم عنصر نائب فقط + `infra/environments/README.md` (TLS/أسرار/RLS/مراقبة/backup/restore/تكلفة).
- **الحماية المحلية باقية**: `loadConfig` ما زال يرفض `NODE_ENV=production` وكل URL غير محلي؛
  لم يُعدّل ولا يُستخدم الفاحص لتشغيل إنتاج.
- **rehearsal استعادة محلي** `scripts/p13-restore-rehearsal.mjs`: نسخة اختبار جديدة → مهاجرات →
  بيانات اصطناعية (Tenant/Property/Product/Connection/Exposure ببادئة `P13-`) → تعليق زيادات
  عبر `platform_stop_tenant_sales` → `pg_dump` → `pg_restore` لقاعدة ثانية → تحقق عدّادات
  وجمودة التعليق وغياب أي زيادة → قياس RPO/RTO → تنظيف. يثبت أيضاً أن كتابة بعد بدء النسخة
  لا تظهر بعد الاستعادة (حد الفقد المقاس) وأن فتح البيع يبقى إجراءً صريحاً لاحقاً.
