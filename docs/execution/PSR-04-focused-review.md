# مراجعة PSR-04 المركزة

24 سبتمبر2026. بتفويض المستخدم، مع قيد تشغيل الاختبارات المتعلقة فقط. مراجعة كود مستقلة بواسطة الوكيل `psr04_review`، واختبارات وإصلاح بواسطة المنفذ الأساسي. لا مراجعة شاملة للمشروع ولا قبول ذاتي للمرحلة.

## النتيجة

**PSR04-R01 — P2، مغلق محلياً:** المعاينة لم تعرض ثلاث قيود معروفة للتنفيذ: max_leaves_per_product، horizon_nights، وعمق المواقع32. ثبتت بثلاثة اختبارات فاشلة قبل الإصلاح. كانت الكتابة ترفض أو تتراجع بأمان؛ العيب في دقة المعاينة قبل تأكيد المستخدم.

أضيفت الفحوص إلى previewV2 التي يستهلكها applyV2 نفسه؛ لم تتغير الحدود أو صلاحياتSQL. خطأ أفق التسعير يرجع step=PRICING. المراجع المستقل أعاد قراءة الإصلاح وأعطى GO مركزاً بعد نجاح اختبارات الإصلاح، دون ملاحظة مانعة جديدة.

## الدليل

- `tests/property/psr04-review.pg.test.mjs`: ملف جديد، بيانات اصطناعية وقاعدة اختبار مؤقتة.
- حجب composition.manage أوrate.manage مع بقاء إدارة الموارد: رفض التنفيذ. سحب الصلاحية بعد النجاح: رفض replay قبل إعادة الرد المحفوظ.
- حقن فشل في nightly_price وapi_idempotency وaudit_event: تراجع المواقع والموارد والمنتجات والأسعار والإصدارات والإكمال؛ إعادة المحاولة بالمفتاح نفسه تنجح.
- حجب غرفة بعد معاينة جناح: PREVIEW_STALE. مرجع من منشأة أخرى داخل مسودة مخزنة عُدلت اصطناعياً: CROSS_SCOPE_REFERENCE؛ لا منتجات جديدة.
- إقامة تعبر نهاية صلاحية التركيبة: RESOURCE_UNAVAILABLE وصفر تخصيصات.
- حدود المعاينة الثلاثة: رفض ظاهر قبل الكتابة، منها عمق33 فوق32 عقدة قائمة.
