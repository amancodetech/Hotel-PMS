## PSR-06.1 — تسمية/مكان وإضافة وحدات مستقلة داخل منشأة قائمة

## PSR-06.3 — أرشفة/منع حذف مستخدم ومعاينة علاقاته

- الحالة: VERIFIED_LOCAL بعد [PASS المستقل من Astra](PSR-06-3-independent-review.md) بتاريخ1أكتوبر2026؛ PG مستقل4/4 وF-PSR063-R01 مغلق، بلا finding مثبت مفتوح.
- النطاق: PSR-T18 وINV10؛ أرشفة غير حاذفة للمكان (INACTIVE) والوحدة (RETIRED)، مع معاينة علاقاتها وسبب منع مفهوم. لا DELETE جديد أو cascade أو تعديل بيانات مستخدمة.
- السلوك الحالي قبل التعديل: PATCH للموقع كان يسمح INACTIVE ولو له أطفال/وحدات؛ PATCH للوحدة كان يسمح INACTIVE/RETIRED دون فحص الوعود والحصص؛ زر التقاعد كان يكتب فوراً. لا endpoint حذف للموقع أو المورد، ودورAPI لا يملك DELETE عليهما.
- السلوك المنفذ: GET `locations/:id/archive-preview` و`resources/:id/archive-preview` يعيدان counts/blockers فقط عبر ResourcesController القائم وصلاحية property.read، دون بيانات نزيل/حجز/مال. LOCATION_IN_USE422 يمنع تعطيل المكان مع أي أطفال أو وحدات مرتبطة؛ RESOURCE_IN_USE422 يمنع تعطيل/تقاعد الوحدة مع أطفال أو التزام حي/مستقبلي أو إقامة مفتوحة/مخططة أو حصة قناة لم تُحرر، ولو UNKNOWN وفترتها الماضية. HOLD المنتهي بوقت قاعدة البيانات لا يمنع الأرشفة؛ تاريخ allocations والمنتجات والتركيبات لا يمنعها بمفرده ويبقى محفوظاً.
- المعاينة والكتابة تمسكان قفل المنشأة scoped. PATCH يعيد فحص نسخة الكيان والعلاقات داخل معاملته، ولا يعتمد على eligible قديمة. الحصرية وحدود تاريخ الإقامة [arrival,departure) محفوظة، ويستعمل يوم المنشأة للفترات. لا تغيير لحالات التعرض أو تحرير allocation أو دفتر عند رفض الأرشفة أو قبولها.
- الواجهة: حوار مشترك في تبويبي الأماكن والوحدات يعرض العلاقات وأسباب المنع، والتأكيد معطل حتى وصول معاينة مؤهلة. التأكيد PATCH بالنسخة المعروضة؛ الرفض يبقي الحوار ويحدث المعاينة، والنجاح يحدث القراءة. panel المكان صار scoped بمفتاح tenant/property مثل المورد. النصوص عربية/إنجليزية/إندونيسية؛ استخدمت إرشادات React في المكوّن المتغير فقط.
- العقد: إضافة ArchiveImpact وعمليتي GET في مصدر phase4 مع صلاحية القراءة ورد422 موثق للكتابة؛ generated أُعيد توليده من المصدر. DTO الاستجابة كائن counts مضبوط من الخدمة، والعميل يستعمل النوع المولد. لا هجرة أو تغير grants/RLS.
- ملفات التطبيق: `packages/backend/src/modules/property/application/archive-impact-service.ts` و`resource-service.ts` و`domain/errors.ts` و`index.ts`؛ `apps/api/src/property/resource.controller.ts` و`operations.ts`؛ `apps/web/src/api/property.ts` و`property/ArchiveEntityDialog.tsx` و`PropertySetupPage.tsx`؛ مصدر phase4 ومخرجه المولد؛ اللغات الثلاث. إصلاح فهرسة الاختبارات في `jest.config.mjs` الأساسي فقط؛ الأرشيف محفوظ.
