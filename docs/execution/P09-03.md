## السلوك المنفذ وحدوده

- `GetOperationsBoard`: لقطة تشغيل بتاريخ عمل المنشأة (حزم المهام الخمس + DND + إشعارات +
  عدّاد غير المقروء) بعقد `task.read` وبلا أي هوية ضيف أو مال في عرض المهمة.
- `ops_shift_handover`: تسليم وردية بعدّادات لحظية (مهام/أوامر مفتوحة، DND نشط) ومرجع جلسة
  صندوق اختياري بلقطة (`expected/counted/variance/currency`) **لا يستبدل دفتر الصندوق**.
- `ops_notification` + `ops_notification_receipt`: إشعارات داخلية (طارئ صيانة CRITICAL،
  مهمة بانتظار الفحص WARNING، تسليم وردية INFO) بوصول لكل عضو وإيصالات قراءة؛ لا Adapter
  خارجي ولا رسائل OTA.
- واجهة `/properties/:id/operations` بتبويبات التدبير/الصيانة/DND/تسليم الوردية/الإشعارات،
  وسياسة التشغيل، ودورة الخروج→الجاهزية كاملة عبر الواجهة، بثلاث لغات وRTL و390px.
- الحدود: لا OTA ولا مراسلات (P14)، لا تغيير لدفتر الصندوق، وG-09 لا تُقبل إلا بقرار المستخدم.
