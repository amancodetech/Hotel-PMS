# P05-01 خطط الأسعار والأسعار الليلية

التاريخ: 14 سبتمبر 2026. الحالة: IMPLEMENTED / VERIFIED محلياً.

## السلوك المنفذ وحدوده

- `rate_plan`: خطة سعر داخل Property مرتبطة بمنتج واحد، بعملة الخطة (IDR/USD)، إشغال أساس،
  وجبة، مزايا (inclusions)، سياسة إلغاء/مجانية، حالة DRAFT→ACTIVE→SUSPENDED→RETIRED وversion.
- `rate_policy_version`: لقطة ثابتة لكل تغيير في سياسة الخطة؛ الأسعار والاقتباسات تشير للقطة
  ولا تتغير بتعديل الخطة لاحقاً (PRICE-001).
- `nightly_price`: سعر ليلة/إشغال داخل خطة؛ decimal(20,6) وفق D-14؛ فريد (خطة/تاريخ/إشغال).
- `price_quote`: اقتباس ثابت (snapshot) بسعر كل ليلة ومجموعه، inventory_version موسوم؛
  يستخدمه Hold/Confirm لاحقاً عبر `price_snapshot_id`؛ لا يغير Posted ولا ينشئ حجزاً.
- `SetRates` batch ذري كامل: كل الخلايا تنجح أو لا شيء؛ قفل Property مرة واحدة.
- سعر صفر مسموح فقط إذا `free_policy`؛ IDR كسري: يرفض عند النشر لقناة لا تقبل كسور IDR
  دون تقريب صامت (يقع الفحص في P05-05 عند Preview/Publish).
- Mapping: يقبل `internal_rate_ref` لخطة موجودة في نفس Property/المنتج؛ خارج النطاق يرفض
  (CROSS_SCOPE_REFERENCE). التفعيل والربط الكامل شرط النشر لا الإنشاء.
- حد الأفق: تاريخ السعر داخل `horizon_nights` من تاريخ تشغيل المنشأة (PERF-01) — يرفض
  LIMIT_EXCEEDED خارجه عند SetRates.

## API / الصلاحيات / الأحداث

- `ListRatePlans` GET `/rate-plans` — `rate.manage` (قراءة أسعار للإدارة).
- `CreateRatePlan` POST `/rate-plans` — `rate.manage` + CSRF.
- `UpdateRatePlan` PATCH `/rate-plans/{ratePlanId}` — `rate.manage` + CSRF + If-Match.
- `SetRates` POST `/rates/batch` — `rate.manage` + CSRF (operationId من v1).
- `QuoteStay` انتقل إلى P05-03 لاعتماده على قيود الضمان.
- (تاريخياً) `QuoteStay` POST `/quotes` — `reservation.read` + CSRF: يحسب ويحفظ snapshot.
- `SaveMapping` (v1 الموجود) يقبل الآن `internal_rate_ref` ويتحقق منه.
- أحداث: `RatesUpdated` (اختياري خارجي لاحقاً)؛ لا نشر OTA من هذه الحزمة قبل exposure.
