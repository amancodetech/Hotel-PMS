# P12-04: إصلاح F-RVW12-01..03 (idempotency الـonboarding، تحصين الفاعل، تجديد دليل القاعدة)

الحالة: **IMPLEMENTED / VERIFIED محلياً** (lifecycle 6/6، support 4/4، property الكامل 314/314 في 43 حزمة،
والبصريات كلها خضراء). التاريخ: 17 سبتمبر 2026. المنفذ: جلسة P12 بعد تفويض المستخدم الصريح لحزمة
إصلاح شاملة إثر المراجعة المستقلة [docs/85](../85_phase12_independent_review.md).

## السياق والتفويض

- المراجعة المستقلة المركزة لـG-12 انتهت **PASS WITH FINDINGS** بلا finding عالٍ: F-RVW12-01
  (متوسط، غير مانع) إعادة مفتاح `OnboardPlatformTenant` بمحتوى مختلف تنشئ منشأة ثانية بدل
  `409 IDEMPOTENCY_CONFLICT`؛ F-RVW12-02 (منخفض، أدلة) ملف `db-evidence` سبق مهاجرة التحصين؛
  F-RVW12-03 (منخفض، تحصين) دوال المنصة تثق بوسيط `p_actor` دون ربطه بسياق الجلسة.
- المستخدم فوّض **إصلاحاً شاملاً** للثلاثة (قرار صريح في الجلسة)؛ القبول يبقى قراره والنطاق
  المحلي لم يتغير: لا نشر ولا مزود ولا قناة/بوابة دفع ولا commit/remote.

## السلوك المنفذ وحدوده

- **F-RVW12-01 (idempotency عالمي للـonboarding)**: جدول `platform_onboarding_request`
  (مفتاح فريد + بصمة SHA-256 لمحتوى الطلب المطبع `[name, slug, customer_label, plan_code,
  owner_email, reason]` بعد التطبيع + الاستجابة المخزنة + Tenant) يُكتب في **معاملة الإنشاء نفسها**.
  نفس المفتاح بالمحتوى نفسه ⇒ النتيجة المخزنة `replayed=true` بلا أثر جديد (بما فيها المفاتيح
  السابقة للجدول: يبقى مسار replay عبر `platform_lifecycle_event`). المفتاح نفسه بمحتوى مختلف ⇒
  **409 `IDEMPOTENCY_CONFLICT`** بلا إنشاء. تحت التزامن: قيد الفرادة يحسم الأمر، والخاسر إما
  replay مطابق أو رفض مغلق بلا منشأة ثانية/اشتراك ثانٍ/فاتورة إدارية مكررة.
- **F-RVW12-03 (ربط الفاعل بالجلسة)**: ثماني دوال `security definer` (`platform_create_tenant`,
  `platform_lifecycle_snapshot`, `platform_set_tenant_status`, `platform_stop_tenant_sales`,
  `platform_resume_tenant_sales`, `platform_record_tenant_audit`,
  `platform_support_tenant_profile`, `platform_support_tenant_audit`) تشترط الآن
  `p_actor = nullif(current_setting('app.platform_user_id'), '')::uuid` إضافةً إلى فحص
  `is_active_platform_staff`؛ الاستدعاء المباشر بفاعل نشط **بلا سياق مصادق** يُرفض بـ42501.
  مسارات API/Jobs تحدد السياق عبر `setPlatformContext` فلم يتغير سلوكها.
- **F-RVW12-02 (تجديد الدليل)**: دليل قاعدة جديد `.local/verification/P12-04/db-evidence.txt`
  (RLS/force، منح الجدول الجديد، ACL الدوال العشر بلا PUBLIC، الدوال المربوطة بالجلسة، منح
  دالتي الدعم). ملف P12-03 التاريخي تُرك كما هو (شاهد زمني) ولا يُعتمد الآن.
