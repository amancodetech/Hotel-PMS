## شروط التصميم

- عرض موارد الموقع المحدد وأحفاده وفق location_id الفعلي، مع تمييز الغرف عن حاويات الفلل؛ لا تحويل شجرة المواقع إلى شجرة موارد أو استنتاج نسب بديل.
- إكمال جميع صفحات الموارد (limit100 القائم لا يرفع) وجميع صفحات المواقع الفرعية عبر BFS. غرفة بعد المورد100 أو تحت صفحة لاحقة من الشجرة لا تختفي.
- لا عرض «لا غرف» قبل اكتمال مصدري الموارد والشجرة. أي فشل في صفحة لاحقة يبقى خطأ قابلاً لإعادة المحاولة ولا يتحول إلى فراغ ناجح.
- مفاتيح cache مع tenant/property، وشجرة الموقع مع selected location؛ لا استمرار عرض مجموعة الموقع السابق باعتبارها نتيجة الموقع الحالي أثناء التبديل أو الانتقال بين المنشآت.
- لا كتابات أعمال؛ المصدر opt-in في LocationsPanel حتى لا تتغير سلوكيات محدد الأب أو الموارد الأخرى عرضاً.

ملكية المراجع: هذا التقرير و`tests/location-resources-independent.test.tsx`. المنسق وحده يشغل الاختبارات والبناء والمتصفح. يلزم تحقق مصدر جديد وفحص نهائي ومتصفح فعلي لمسار المستخدم؛199اختباراً السابقة دليل للمصدر السابق، لا شهادة لهذا التعديل. قراءة جميع موارد المنشأة المرقمة لها كلفة معروفة؛ لا ادعاء قبول أداء PSR جديد.
