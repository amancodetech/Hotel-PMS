# P02-05: Channex adapter مع HTTP client محقون

الحزمة / التاريخ / المنفذ: P02-05، 13 سبتمبر 2026، Asia/Makassar، نموذج التنفيذ المفوَّض.

الحالة: VERIFIED آلياً بخادم HTTP محلي. لا اتصال حي.

السلوك المنفذ وحدوده: `ChannexAdapter` يطبق `ChannelAdapter` فوق `HttpClient` محقون. القيود الأمنية: allowlist مضيفين، رفض redirect، TLS إلزامي للشبكة الحية، مهلة لكل طلب، حد حجم استجابة، ولا تسجيل لأسرار. الشبكة الحية معطلة افتراضياً (`live:false`)؛ الوصول محدود بالـallowlist. المسارات المستخدمة هي المثبتة في docs/26: `GET /booking_revisions/feed`، `POST /booking_revisions/{id}/ack`، `POST /availability`، `POST /restrictions`. `baseUrl` واسم ترويسة المصادقة ومصدر `secret_ref` كلها محقونة، وتوثيقها النهائي من EX-01/P13؛ لا credential حقيقي في الكود أو الاختبار. التطبيع يقبل شكل feed بسمات وخرائط `ota_name` إلى مفاتيح القنوات، ويحفظ `unmapped_fields` بالأسماء فقط. التنقية تستبدل حاويات النزيل (customer/guest) بمرجع hash وعدد بالغين/أطفال، وتزيل البطاقات والأسرار والاتصال والعنوان والهوية، وترفض الحقن عبر مفاتيح غير معروفة في الجذر. `readProviderState` و`readChannelEvidence` و`inspectMappings` تبقى UNSUPPORTED حتى إثبات endpoint في P13، ولا تدّعي أي قراءة.

المراجع: DIST-001..004/007، AT-A06، AT-C05/09 (طبقة نقل)، P02-05 في docs/32، docs/26، docs/33.

الاعتمادات: P02-01؛ P02-03/04 للاختبار المتكامل لاحقاً.

الملفات المعدلة: `packages/backend/src/modules/distribution/adapters/channex/{http-client,sanitize,normalize,channex-adapter,index}.ts`؛ `domain/hash.ts` (مشترك)؛ تصدير في `modules/distribution/index.ts`؛ `tests/distribution/channex.test.mjs`.

تغيير API / schema / permission / event: لا شيء؛ لا endpoints عامة.

Migration: لا شيء.

الاختبارات: `NODE_OPTIONS=--experimental-vm-modules pnpm exec jest --runInBand tests/distribution` → 34/34 وقتها (تشمل 5 لChannex). تثبت: تطبيع صفحتين وcursor معتم وتسلسل، تنقية كاملة (لا رقم بطاقة/بريد/اسم في التسلسل)، ack 200/404/429 مع Retry-After/500، timeout بعد الإرسال = UNKNOWN وليس نجاحاً، رفض الاتصال قبل الإرسال = NOT_SENT، عدم اتباع redirect، رفض مضيف غير مسموح، إرسال خلايا تواريخ مفردة لARI، 200 مع warnings = PARTIAL وليست channel verified، وUNSUPPORTED للقراءة والمطابقة.

الأمن: لا أسرار في الملفات أو الأخطاء؛ التنقية قبل التخزين؛ مهلة وحد حجم؛ لا logging للـpayload.

التبعيات المؤجلة: توثيق `baseUrl`/ترويسة المصادقة/المسارات النهائية وreadback في P13-03 مع EX-01؛ `inspectMappings` و`readChannelEvidence` يبقيان مغلقين حتى الدليل.
