# SET-05 — الكامل/الأجزاء والأسرة والجناح المتصل

الحزمة والمهمة الفرعية: SET-05 بكامل مهامها 05.1..05.5.
نطاق التفويض ومصدره: طلب المستخدم «ابدأ SET-05 وفق docs/94 وdocs/95 وسجل التقدم» مع قائمة مسارات ومعايير صريحة، بعد إغلاق R2 محلياً.
الحالة: **VERIFIED_LOCAL (INDEPENDENT GO)** — 05.1..05.5 مكتملة محلياً؛ عولجت SET05-R01..R03 وO01، وحُسمت السياسة المقيدة بالفشل المغلق، واكتمل E3، وقبلتها [إعادة التحقق المستقلة](SET-05-reverification-report.md). المكتب الأمامي متعدد المكونات وSET-07 لم يُنفذا.
التاريخ: 22 سبتمبر 2026.

## التفويض والثوابت

- لا تعديل لقرارات D، ولا فك `SETUP_MODE_UNSUPPORTED` إلا باكتمال مسار القالب.
- لا جمع حصص خارجية متنافسة (D-20 كما هو)؛ المحاكاة قراءة فقط ولا تنشئ حجزاً ولا حصة.
- لا افتراض لغرف/أسرّة/سعة غير مدخلة. لا إنشاء غرفة وهمية للجناح، ولا استنتاج اتصال من التجاور.
- إعادة استخدام محرك المخزون: الالتزام عبر `commitment` + `plan_allocation` (قيد منع التداخل)، والتركيبات عبر `composition_version` المؤرخة.

## تمثيل المسودة (إضافات)

| الحقل | القالب/الوضع | القاعدة |
| --- | --- | --- |
| `parts: [{label, capacity?}]` | VILLA/APARTMENT + `WHOLE_OR_PARTS` | إلزامي ≥1، labels فريدة `[A-Z0-9-]{1,16}`؛ capacity 1..100 أو ترث سعة المجموعة |
| `connected_codes: string[]` | SUITE | إلزامي ≥2، فريد، أكواد موارد موجودة في المنشأة؛ لا إنشاء موارد |
| `beds_per_unit` + `sharing_scope` | DORM + `BEDS` | `MIXED` فقط في هذه المرحلة؛ `FEMALE/MALE` مرفوضتان حتى يفرض إدخال الحجز أهلية النزيل — **سُلِّمت لاحقاً في SET-07.6**: الفرض الآن عند البيع (مسودة/تأكيد/تعديل) والدخول |
| `setup_unit_code` | VILLA/APARTMENT/DORM/SUITE المركبة | سلوت منطقي ثابت وفريد داخل المنشأة؛ لا ينشئ مورداً مادياً للجناح، وتُشتق إتاحته من أوراق التركيبة |

- `WHOLE_OR_PARTS`: موارد الأجزاء (ROOM) فقط؛ الكامل منتج تركيبة فوق أجزائه. لا مورد إضافي للكامل (docs/04).
- `BEDS`: مورد غرفة أم (ROOM، غير مرتبط بأي منتج) + أسرة فعلية (BED، سعة 1)؛ منتج أسرة للمجموعة + منتج تركيبة لكل غرفة فوق أسرارها؛ لا مورد بيع مضاعف.
- `SUITE`: منتج + تركيبة ACTIVE فوق الموارد المحددة حصراً.
- **سلوت الجناح:** كود النمط المعلن هو هوية البيع المنطقية للجناح (`setup_unit_code`) وليس رقم غرفة أو مورداً جديداً. يفرض قيد قاعدة البيانات تفرده داخل المنشأة، وتبحث المحاكاة به فقط عند عدم وجود مورد مادي بالكود نفسه. أوراق التركيبة وحدها تحمل المخزون والحصرية؛ تعديل الأوراق يتم بنسخة مؤرخة في SET-06.
- نافذة التركيبة: `[today, today + horizon_nights]` (نفس أفق المحرك).

## 05.1 الكامل/الأجزاء

- المدخلات: أجزاء معلنة من المستخدم مع سعة اختيارية.
- القيود: `parts_required` عند اختيار الوضع، `parts_not_allowed` لغيره؛ `DUPLICATE_LEAF` تُرفض من التركيبة؛ حد الدفعة يشمل الموارد + التركيبات.
- القبول: A1 إنشاء N مورد جزء و(N+1) منتج لكل وحدة (N أجزاء + كامل) وتركيبة ACTIVE لكل كامل؛ A2 حجز الكامل يستهلك كل الأجزاء (تزامن كامل×جزء → فائز واحد)؛ A3 حجز جزء يمنع الكامل ويُبقي الأشقاء؛ A4 لا يوجد مورد VILLA/APARTMENT للكامل بجانب الأجزاء؛ A5 استمرارية كاملة: تعارض ليلة واحدة في جزء يمنع الكامل.

## 05.2 الأسرة/الغرف المشتركة

- المدخلات: غرف (pattern) + عدد أسرة + نطاق مشاركة.
- القيود: لا منتج يشير إلى الغرفة الأم؛ الأسرة هي الوحدات القابلة للبيع؛ السعة الفعلية للسرير 1.
- القبول: B1 العدد: موارد الغرف + الأسرة، ولا مضاعفة بيع؛ B2 منتج الأسرة adults_max=1 مع `sharing_scope` محفوظة؛ B3 منتج تركيبة لكل غرفة فوق أسرارها (بيع الغرفة كاملة يستهلك كل الأسرة)؛ B4 تزامن سرير×غرفة → فائز واحد، والأشقاء يبقون متاحين؛ B5 عدادات الغرف/الأسرة منفصلة.

## 05.3 الجناح المتصل

- المدخلات: كود الجناح (pattern رقمي) + أكواد غرف موجودة.
- القيود: لا إنشاء موارد؛ أكواد موجودة في نفس المنشأة فقط؛ تكرار مرفوض؛ أكواد مفقودة → `CROSS_SCOPE_REFERENCE` قبل أي كتابة.
- القبول: C1 عدد الموارد قبل/بعد متساوٍ؛ C2 تركيبة ACTIVE بأوراق = الأكواد المحددة؛ C3 حجز الجناح يستهلك كل غرفه، وحجز غرفة منه يمنع الجناح؛ C4 جناحان يتشاركان غرفة لا يُحجزان معاً؛ C5 حجز مستقبلي على نسخة سابقة يمنع ازدواج المورد عبر نسخة جديدة.

## 05.4 المعاينة والمحاكاة والتزامن

- توسيع المعاينة: أعداد الموارد/الأجزاء/الأسرة/التركيبات لكل قالب، وblockers صادقة.
- عمليتان من العقد: `GetSetupReadiness` و`SimulateSetupSale`.
- القبول: D1 الجاهزية تقرأ النواقص دون أي كتابة أو تغيير حالة؛ D2 المحاكاة WHOLE/PART/BED تُرجع allowed/blocked/available_after صحيحة، ولا تزيد `inventory_version` ولا تنشئ التزاماً؛ D3 تعكس حجزاً قائماً؛ D4 عزل بين الشركات والمنشآت.

## 05.5 الواجهة والعقود والترجمات والاستيراد

- الواجهة: محرر أجزاء صريح (بدل عدّ 3 الوهمي)، واختيار غرف الجناح من موارد المنشأة، ومحاكاة البيع في خطوة المراجعة.
- العقود: `parts`/`connected_codes` + حقول المعاينة + العمليتان؛ إعادة توليد الأنواع.
- الترجمة: مفاتيح جديدة في ar/en-US/id-ID.
- الاستيراد: DORM/SUITE يبقيان مرفوضين صراحةً لأن CSV لا يمثل الأجزاء/الأسرة/الربط؛ VILLA/APARTMENT يبقى EXCLUSIVE.
- القبول: E1 `contracts:check` و9/9 عمليات SET منفذة؛ E2 اختبار استيراد التمييز؛ E3 جولة متصفح للمسارات الثلاثة والمحاكاة؛ E4 لا مفاتيح ناقصة.

## الحدود المعلنة

- المكتب الأمامي متعدد المكونات (دخول/خروج/نقل فيلا كاملة أو جزء أو سرير) = SET-07؛ لم يُنفذ ولم يُدَّع.
- فرض سياسة المشاركة حسب جنس/نوع النزيل يحتاج بيانات النزلاء = SET-07.
- حتى SET-07 لا تعرض الواجهة إلا `MIXED`، ويرفض الخادم `FEMALE/MALE` بـ`SETUP_DRAFT_INVALID`؛ لذلك لا يوجد منتج ACTIVE بوعد غير مفروض. **تحديث SET-07.6 (22 سبتمبر 2026):** رُفع الحجب المؤقت بعد إضافة `guest.gender` وفرض السياسة خادمياً عند البيع والدخول (`GUEST_GENDER_REQUIRED`/`SHARING_POLICY_VIOLATION`)، والمعالج يعرض الأنماط الثلاثة.
- تعديل تركيبة عليها حجز مستقبلي بنسخة مؤرخة جديدة = SET-06؛ ثبت في SET-05 أن حجزاً قائماً يمنع الازدواج عبر نسخة/مسار آخر.
- الاستيراد يستمر برفض DORM/SUITE وكل ما لا يمثله CSV (أجزاء/أسرة/ربط) صراحةً.
- دليل E3 محفوظ داخل مجلد رحلة SET-01 لأن سكربت المتصفح نفسه أعيد استخدامه؛ أسماء الفحوص واللقطة تحدد نطاق SET-05 صراحةً.
