# مراجعة مستقلة لـPSR-03

راجع شجرة المكان وتفاصيل الوحدات وفق docs/100 و101 وبطاقة PSR-03 ودليل PSR-03-operations. لا تعتبر أدلة المنفذ قبولاً مستقلاً. تنفيذ مسودة v2 وربط واجهة الشجرة في المرحلتين04/05 التاليتين.

## نقاط التحقيق

1. افحص الهجرة الجديدة: المواقع القديمة جذور غير مصنفة؛ الهويات والأكواد والحالات والمبالغ محفوظة؛ FK مركب وRLS مستمر؛ لا موارد مشتقة من الوصف.
2. جرّب أباً من منشأة أو شركة أخرى، ودورة ذاتية ومتعددة العقد، وسباق نقل A تحت B مقابل B تحت A. تحقق من قفل المنشأة قبل الموقع، ومنع الدورة في SQL، وعدم ظهور500 في سباق API.
3. جرّب عمق32 ثم33، ونقل شجرة فرعية يتجاوز مجموع عمقها الحد. فشل العملية لا يغيّر الشجرة أو سجل التدقيق جزئياً.
4. قارن GET القديم وtree=true: الحدود، الأب، المسار، والترتيب. جرّب مؤشراً معدلاً أو من أب/منشأة أخرى أو بعد تغيير الشجرة. راجع فهرس الأطفال وعدم تحميل الموارد. التوقيع محلي لعملية API؛ ليس دعماً لتعدد النسخ.
5. أنشئ موقعاً بمفتاح تكرار مرتين، ثم بمحتوى مختلف، ثم بصفة قارئ أو بعد الأرشفة. افحص CSRF وإصدار PATCH. إغفال الأب يحفظه وnull يفصله.
6. عطّل سلفاً وحاول إسناد مورد أو استيراده أو إنشاءه عبر SET القديم تحته. لا تغييرات خفية للحجوزات القائمة. نقل أو تسمية المكان يغيّر location_tree_revision فقط، دون inventory_version.
7. ضع اسم عرض101 في مبنيين بكودين مختلفين، ثم حاول تكرار الكود الداخلي. عدّل location_id وتحقق من انتقاله فعلاً. جرّب تفاصيل مجهولة المفاتيح وأعداداً سالبة وكسرية وصفراً؛ لا غرف وهمية أو سعة مشتقة.
8. اختبر CSV القديم بصفوف صالحة ومكررة وغير صالحة وصيغ ومواقع خارجية أو غير نشطة. DRY_RUN لا ينشئ موارد. APPLY ينفذ المقبول معاً ويعرض المرفوض؛ تعارض الكود يبطل إنشاء الصفوف المقبولة كلها.
9. على قاعدة معزولة: down قبل استخدام الحقول ثم up مع مقارنة القيم؛ بعد استخدامها يرفض down قبل DDL. تحقق من سجل الهجرة. لا تستعد نسخة فوق قاعدة المستخدم. خطة restore ليست اختبار استعادة منفذاً.
10. طابق OpenAPI وDTO والعميل والأنواع المولدة ومستهلكي Location/Resource. أعد الطقم المركّز وأضف فحوصاً مضادة مستقلة.

## المخرجات

اكتب `PSR-03-independent-review.md` بحكم GO أو NEEDS_FIXES، ونتائج بمعرف PSR03-Rxx وشدة ومسار وخطوات إعادة إنتاج. حدد ما لم تختبره. لا تعدّل D أو G-13 ولا ترفع الحالة إلى ACCEPTED_LOCAL؛ القبول قرار المستخدم.
