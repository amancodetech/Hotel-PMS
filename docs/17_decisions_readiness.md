## مخاطر قائمة

تسرب عميل: اختبارات نطاق وRLS. تعقيد تركيب: تحقق قابلية وحدود معلنة. حجز خارجي متعارض: استثناء ومطابقة لا إسقاط. دفع مجهول: reconciliation لا تكرار. فساد إغلاق يوم: حاجز وترحيل وحيد. اختلاف السوق: تحقق محلي قبل الإنتاج. Scope creep: مصفوفة قدرات وV1 صريح. استعادة قديمة مقابل مزود حديث: مطابقة قبل الإرسال. مراسلات القنوات: فصل صلاحيات الحجز عن الرسائل، وعدم دمج الهوية بالاسم أو ادعاء التسليم، وإيقاف الرسائل المجدولة عند تغير حالة الحجز.

## الجاهزية

مكتمل كتصميم: نطاق V1 وسياسات المخزون والمال، أدلة عامة ومقارنة طرق الاتصال، ERD منطقي مع القيود، عقد OpenAPI أساسي وكتالوج عملياته وصلاحياتها وأحداثها، وخطة قبول وتشغيل. مراجع التنفيذ docs/22..27 وdocs/contracts/v1.openapi.json.

المتبقي خارجياً EX-01..05: قبول المزود وإثبات قدرات D-20، تفويض المنشآت وبيانات النقل، الامتثال المحلي، قياسات الأداء والاستعادة، والموافقة على الإنفاق والنشر. جميع الاتصالات NOT_TESTED / NOT_AUTHORIZED. لا يعني القرار أن المزود التزم بتطبيقه.

G-00 استوفت تفويض تنفيذ المرحلة 1. تحديث 13 سبتمبر 2026: الأساس الهندسي منفذ ومختبر آلياً وفق docs/29_phase1_verification.md؛ قبول G-01 الكامل ينتظر Computer Use. تمت تهيئة Git المحلي في .git الموجود دون استبداله، ولا remote أو commit. عقد V1 يغطي المسار الأساسي المخطط ولا يدعي جرد كل endpoint أو تنفيذه؛ مسارات الصحة المنفذة منفصلة في contracts/foundation.openapi.json. تنقح عقود الوحدات ضمن بواباتها قبل تنفيذها مع الحفاظ على القرارات والثوابت.
