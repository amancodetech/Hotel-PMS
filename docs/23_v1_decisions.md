# الإصدار الأول: قرارات النطاق

الحالة: قرارات تصميم معتمدة بالتفويض من طلب المستخدم إكمال الخطوات كلها بإتقان، 12 سبتمبر 2026. ليست شهادات تنفيذ أو اتفاقات مع مزودين. سجل D في docs/17_decisions_readiness.md هو الفهرس الحاكم.

## تعريف الإطلاق D-01

V1 التجاري هو PMS تشغيلي مع Channel Manager للقنوات الخمس المطلوبة بعد المراحل 0..13 وبواباتها. نحافظ على ترتيب المراحل؛ أولوية القنوات تعني أن كل مرحلة تبني المتطلبات اللازمة لها. تشغيل تجريبي قبلها يكون ببيانات اصطناعية، ثم pilot محدود في المرحلة 13 بوصف معلن للقنوات المفعلة. لا يسمى الاتصال بقناة واحدة اكتمال وعد القنوات الخمس، ولا يشترط أن تمتلك كل منشأة حساباً لدى كل قناة.

يغطي V1 الغرف والفلل والشقق والأسرة والمواقع والخيام والأكواخ والبيت والوحدات المركبة المعرفة. دعم نمط المورد مشروط بقبوله لدى OTA ونجاح اختبارات نوعه، وليس وعداً بأن كل قناة تبيع كل نوع. موارد الخدمات ذات المواعيد لا تدخل في معنى «كل أنواع الإقامة».

| القدرة | قرار V1 |
|---|---|
| CAP-01/02/03 | حجز مورد أو نوع وضمان داخلي مثبت؛ مركبات معرفة مسبقاً والأسرة مع حصرية الغرفة |
| CAP-04/10 | يومي وأسبوعي وشهري؛ رسوم دورية بسيطة وتقسيم رسوم بين دافعين داخل المنشأة |
| CAP-06 | حجز متعدد البنود وحصة مجموعة محددة الموارد والمهلة؛ Pickup ينقل الالتزام ولا يضاعفه |
| CAP-07 | باقات بسيطة بإضافات كمية ونسخة سعر؛ الوجبات ذات المخزون الزمني مستبعدة |
| CAP-09/16 | تنظيف وصيانة وBlocks ومهام وتسليم وردية واستمرارية وإشعارات تشغيلية |
| CAP-11 | تأمين أضرار منفصل وإقامة مالك تستهلك المخزون مع تصنيف الإيراد الصحيح |

الصلاحيات المؤسسية والعزل واللغات الثلاث والعملتان متطلبات إطلاق لجميع الوحدات. لا GL شامل أو مشتريات أو رواتب أو ذكاء اصطناعي في V1. لا أولوية داخل المرحلة 14 مفروضة بين المراسلات والحجز المباشر؛ يؤكد D-15 تأجيل المراسلات فقط.

## حسم السياسات

| ID | القرار المفوض | السبب والأثر |
|---|---|---|
| D-02 | تراكيب مسبقة التعريف بنسخ مؤرخة، تدعم التداخل ومتعدد المستويات والأجزاء المختلفة؛ لا تركيب اعتباطي ينشئه النزيل عند الحجز | تسطيح إلى موارد ذرية، ثبات النسخة القديمة وفحص المستقبل |
| D-03 | تثبيت موارد داخلياً عند كل Hold أو تأكيد، مع خطة قابلة للتحقق؛ إعادة تخطيط صريحة وذرية فقط | لا ضمان بعدادات يومية؛ RoomAssignment منفصل ولا يعد النزيل برقم المورد المخطط |
| D-04 | بحث محدود بملف حدود مؤرخ وفشل مغلق؛ ملف القياس الابتدائي في docs/24_inventory_design.md | لا وعد أداء غير مقاس؛ تجاوز حدود الحجز الداخلي يرفض، والحجز الخارجي الكبير يحفظ استثناءً |
| D-06 | فوترة دورية بسيطة بمقاطع لا تتداخل، وباقات كمية غير زمنية؛ دفاتر فعلية في المرحلة 8 | إقامة طويلة قابلة للتشغيل دون محرك اشتراكات ضيوف معقد |
| D-07 | الليالي فقط في V1؛ تأجيل النهاري/بالساعة إلى 14، مع أوقات وصول وتجهيز فعلية | مخزون OTA الليلي لا يستخدم لتأكيد خدمة زمنية مختلفة |
| D-08 | OOO خارج المقام التشغيلي المؤهل، OOS ضمنه مع إظهار أيام التعطل؛ عرض المقام الفيزيائي الأصلي دائماً | مؤشرات كل نوع مورد منفصلة؛ لا جمع غرف وأسرة أو عرض فيلا مع أجزائها |
| D-09 | لا overbooking داخلي مقصود؛ الأنشطة وتسويات الملاك بعد الإطلاق؛ إقامة المالك وتحصيل التأمين داخل V1 | قبول خارجي زائد يبقى استثناءً وليس غرفة وهمية |
| D-10 | لا كتابة تؤكد مخزوناً عالمياً Offline؛ عرض آخر بيانات مع توقيتها وخطة يدوية للمطابقة | لا queue تأكيدات خفية عند العودة؛ تنفذ الطلبات بعد تحقق جديد |
| D-13 | السماح بالمغادرة التشغيلية برصيد بعد تحويله إلى ذمة مصرح بها؛ لا reopen ليوم مغلق | CLOSING يمنع الترحيل الجاري ويعيد BUSY حتى يفتح اليوم التالي؛ التصحيح في يوم مفتوح |
| D-14 | دفتر فرعي متوازن ثنائي القيد، Decimal وحفظ الأصل والتحويل؛ IDR/USD بدقة ترحيل منزلتين، HALF_UP لكل بند ثم الجمع | إذا مزود لا يقبل كسور IDR ترفض القيمة أو تعتمد نسخة سعر جديدة قبل الإرسال؛ لا تقريب صامت للمستند المنشور |

حدود الدقة قرار تمثيل مالي لا فتوى ضريبية. الحساب الوسيط يصل إلى 6 منازل؛ فروق التقريب والتحويل قيود منفصلة معلنة. التوازن لكل عملة ولكل Journal؛ FX عبر حسابات تسوية مرتبطة لا جمع IDR مع USD. الدفتر التشغيلي لا يصبح تلقائياً دفتر امتثال محلي.

## الدفع والضرائب ضمن D-11

V1 يدعم تحصيلاً نقدياً وتحويلاً بنكياً وتسويات OTA وإثبات مدفوعات POS خارجية مع مرجع ودليل ومطابقة. لا معالجة PAN/CVV أو تحصيل VCC داخل التطبيق. الاسترداد الخارجي يسجل Pending حتى دليل التنفيذ؛ يمنع جمع طلبه ونجاحه في خطوة وهمية. اشتراك SaaS يفوتر إدارياً وتدار استحقاقاته مع audit؛ بوابة دفع آلية ليست شرط هذا الإصدار. بذلك لا يتوقف اختيار بنية المرحلة 1 على شراء PSP.

سعر الصرف يؤخذ في V1 من سعر تسوية موثق أو إدخال مصرح مع مصدر وتاريخ واتجاه وموافقة مستقلّة قبل الترحيل. لا FX live feed مطلوب للإطلاق. إعداد الضريبة والفاتورة القانوني لكل منشأة يبقى شرط إنتاج EX-03؛ لا نخترع نسبة ضريبة موحدة لإندونيسيا. المخزون يعمل مستقلاً عن تحصيل الدفع المجهول.

## تقييم الاكتمال

التصميم هنا يحسم الخيارات التي يمكن حسمها دون حسابات خارجية. بوابة الإنتاج تتطلب قبول المزود، تهيئة منشآت فعلية مصرح بها، اختبارات التزامن والاستعادة والعزل، وملف السوق. هذه أعمال محددة في docs/27_readiness_gates.md وليست أسئلة نطاق نكررها للمستخدم.
