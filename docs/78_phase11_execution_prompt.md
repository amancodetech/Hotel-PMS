## كيف تُدار الجلسة

1. **قبل الانطلاق**: تأكد من `G-10 = ACCEPTED` في [G-10](execution/G-10.md) وأنه لا finding
   مفتوحاً؛ وتأكد من حالة البيئة والمنافذ (api 4100 / web 5173 / worker 4101) وأوقف dev
   قبل الأطقم الرسمية.
2. **خلال P11**: حزمة واحدة لكل دورة، مع بطاقة أدلة، وعدم إنشاء أي كتابة على `journal` أو
   `business_day` أو `folio_charge` أو `night_audit_*` — التقارير قراءة فقط.
3. **عند G-11**: جهّز حزمة الأدلة (تقرير تنفيذ + أرقام خام + أثر قاعدة البيانات + عزل/تصدير
   + بصريات شاشة التقارير). **المراجعة المستقلة ليست إلزامية لـG-11** وفق docs/34؛ إن طلب
   المستخدم تأكيداً مستقلاً تُكتب حزمة مراجعة بنمط docs/75 والحكم في ملف مستقل.
4. **الحدود**: لا تُفتح P12 (SaaS) ولا P13 (القنوات) ولا أي بوابة أخرى؛ اعتماد P10 → P11
   تم بقرار المستخدم على G-10، ولا يُعلن أي جاهزية إنتاج.
