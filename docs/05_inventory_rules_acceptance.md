## دورات الحالة

- Commitment: مؤقت → مؤكد → قيد الاستخدام → مستوفى؛ مؤقت → منقضٍ/محرر؛ مؤكد → محرر وفق إلغاء. تقصير يحرر فترة لا تاريخاً مستخدماً. دخول لا يخصم مرة ثانية.
- Hold: نشط → محوّل/محرر/منتهٍ. لا إحياء بعد الانتهاء، والتحقق من الوقت مباشر حتى لو تأخر العامل.
- Block: مسودة → مجدول → فعّال → منتهٍ، أو إلغاء موثق. نهاية الوقت لا تعوّض فحص إصلاح مطلوب.
- Assignment: مقترح → مثبت → مستخدم → منتهٍ؛ مثبت → مسحوب؛ مثبت/مستخدم → مستبدل بتاريخ وبديل متسق. إزالة التخصيص لا تزيل ضمان الالتزام.
- Disruption: مفتوح → قيد المعالجة → بديل مقترح → محلول أو مصعّد. مستقل عن بقاء الحجز التجاري.
- Availability/Readiness/Occupancy نتائج مشتقة لا تُحرر مباشرة. اللقطات لا تصبح مصدر الحقيقة.
