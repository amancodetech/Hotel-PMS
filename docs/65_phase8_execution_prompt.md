## كيف تُدار الجلسة

1. **قبل الانطلاق**: تأكد من قبول G-07 وأن لا finding حاجباً مفتوحاً؛ وتأكد من موقف D-14
   (إن لم يُحسم توقف واسأل).
2. **خلال P08**: حزمة واحدة لكل دورة، مع بطاقة أدلة، وإبقاء dev متوقفاً عند الأطقم.
3. **عند G-08**: جهّز حزمة مراجعة مستقلة (تقرير تنفيذ + أدلة + أسئلة) ولا تعلن القبول؛
   تُشغَّل جلسة مستقلة بنمط docs/53/docs/61، والقبول قرار المستخدم.

## حدود صريحة

- لا مزود دفع أو FX حقيقي ولا PAN/CVV ولا أرصدة نقدية حقيقية؛ synthetic فقط مع تسجيل الاستثناء.
- لا تغيير لترتيب المراحل أو النموذج المالي أو حدود العزل.
- ما قبل P08 (clearance التشغيلي) يبقى كما في P07: لا تسوية قبل G-08 والقبول.
