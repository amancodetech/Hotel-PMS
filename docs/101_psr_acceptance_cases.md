قاعدة معزولة جديدة لكل تشغيل وفق harness المشروع. شركتان TA/TB؛ منشأتان PA/PA2 في TA ومنشأة PB في TB؛ مالك TA، قارئ TA، وعضو محدود بـPA2. معرفات مولدة في التشغيل لا UUID من dev. رموز تبدأ PSR ورقم تشغيل؛ لا نزلاء حقيقيون. اعتمد يوماً محلياً T بساعة الاختبار الحالية، وإقامة [T+10,T+12)، مع أسعار صحيحة وموارد جاهزة حيث يتطلب الحجز ذلك. لا تخترع endpoint أو تتجاوز قواعد الحجز لتهيئة fixture.

## سلم التحقق

- بطاقة وثائق/عقد: فحص روابط/تنسيق، ثم توليد وفحص العقد عند تغييره.
- قاعدة كتابة: PostgreSQL مركز للنجاح والرفض والسباق، وفحص أثر البيانات لا مجرد HTTP.
- الواجهة: متصفح فعلي للمسار وتسجيل أخطاء الصفحة؛ لقطة وحدها لا تثبت الحفظ.
- نهاية الحزمة: check للكود؛ توسيع property/identity/distribution حسب خريطة الأثر.
- نهاية الدفعة: انحدارات SET المتأثرة، واختبارات الجدول ضمن النطاق، ومراجعة مستقلة؛ سجل الباقي NOT_TESTED/DEFERRED بصراحة.
