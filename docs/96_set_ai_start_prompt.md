# رسالة جاهزة للنموذج المنفذ

التاريخ: 21 سبتمبر 2026. انسخ الكتلة التالية واملأ سطر التفويض بما ترغب فعلاً في السماح به. هذه الرسالة ليست تفويضاً من ملف داخل المستودع؛ تصبح تعليمات عمل حين يرسلها المستخدم ضمن نطاقه.

```text
اعمل في /home/omar/Desktop/Hotel على خطة إعداد المنشآت والوحدات SET.
نطاق التفويض لهذه الجلسة: [حدد: تحليل SET-00 فقط، أو تنفيذ محلي لحزم محددة، أو جميع حزم SET المحلية مع استثناء الأفعال الخارجية].

اقرأ AGENTS.md وREADME.md وdocs/01_baseline.md وdocs/17_decisions_readiness.md
وdocs/18_cli_handoff.md، ثم:
- docs/94_property_setup_and_inventory_plan.md: المتطلبات والتبعيات ومعايير القبول.
- docs/95_set_ai_implementation_playbook.md: طريقة العمل وقائمة أثر الباك إند.
- docs/execution/SET-progress.md: الحالة والخطوة التالية.

لا تستخدم ملخص المحادثة بدلاً من الملفات والكود. ابدأ بالتحقق من التفويض وgit status
والتغييرات المحلية وأي تعليمات فرعية. لا تحذف عملاً سابقاً أو تفترض أن ملفات untracked زائدة.
إذا كان سجل التقدم فارغاً، ابدأ SET-00. إذا كان مكتوباً، تحقق من صحته واستأنف أول مهمة غير مكتملة.

نفذ مهمة فرعية واحدة في كل دورة، واكتب بطاقة للحزمة عند بدايتها.
قبل تغيير أي باك إند تتبع المسار كاملاً من الواجهة إلى API والخدمة والمعاملة والقاعدة
ثم الاستجابة والأحداث والمستهلكين. املأ قائمة أثر القسم 5 في docs/95؛ كل صف DONE أو N/A بسبب.
لا يكفي تعديل endpoint أو نجاح build لإغلاق المهمة.

حافظ على العزل والصلاحيات وRLS وقفل المخزون والتركيبات المؤرخة والتكرار الآمن وD-20.
لا تعدل ملفات العقود المولدة يدوياً ولا هجرة مطبقة. لا تنشئ قاعدة أو محرك مخزون موازياً.
حدث OpenAPI/DTO/generated/client/الواجهة/اللغات/الأحداث/الاختبارات عندما يتأثر أي منها.
اختبر الرفض والفشل والتزامن بحسب المخاطر، وافحص حالة البيانات لا HTTP فقط.

استخدم أوامر المشروع الموجودة بعد قراءتها. fast لا يبني؛ ابن النسخة قبل اختباره.
لا تشغل أطقم تتنافس على المنافذ معاً. لا توقف عملية إلا بعد إثبات أنها تخص هذا المشروع.
لا تعرض أسراراً ولا تستخدم بيانات ضيوف حقيقية. لا تنفذ إجراءً خارجياً دون تفويضه.

حدث docs/execution/SET-progress.md وبطاقة الحزمة بعد كل مهمة وقبل نهاية الجلسة:
ما أنجز، ملفات/عقود/هجرات متأثرة، الأمر والنتيجة والأدلة، ما لم يختبر، والعائق والخطوة التالية.
لا تضع VERIFIED_LOCAL دون فحوص الحزمة، ولا ACCEPTED دون قرار القبول.
لا تغيّر مراحل المشروع أو قرارات D أو بوابات G/EX ضمنياً.

استمر داخل التفويض دون إعادة سؤال المستخدم عن خطوات روتينية سبق تفويضها.
إذا احتجت قراراً جديداً، اسأل سؤالاً محدداً وواصل الجزء المستقل المتاح.
في النهاية سلم النتيجة الفعلية وحدودها وروابط الأدلة، لا قائمة وعود.
```

رسالة استئناف مختصرة بعد تفويض سابق مستمر:

```text
استأنف خطة SET ضمن التفويض السابق المسجل، وفق docs/95_set_ai_implementation_playbook.md.
تحقق من docs/execution/SET-progress.md وبطاقة الحزمة النشطة والكود الفعلي، ثم أكمل أول مهمة
غير منجزة. لا تعاود البداية أو تفترض نجاح اختبارات غير موثقة. حدث التسليم قبل إنهاء الجلسة.
```
