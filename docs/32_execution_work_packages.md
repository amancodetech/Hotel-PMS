[سجل التنفيذ](34_implementer_handoff.md) يحفظ النتائج الفعلية.

## قواعد مشتركة لكل حزمة

التسلسل الافتراضي داخل كل مرحلة هو ترتيب الحزم؛ تعتمد أول حزمة على إغلاق بوابة المرحلة السابقة. الاعتماد المذكور داخل الصف إضافة إلى ذلك، وليس إذناً بتجاوز الترتيب. كل حزمة تقرأ README وbaseline وحالتها الفعلية، ثم القراءات المحددة للمرحلة. لا يتطلب العمل تحميل references التاريخية كلها.

الملكية أدناه للمسارات المقترحة تحت `packages/backend/src/modules`، مع `apps/api` للنقل و`apps/worker` للمستهلك و`apps/web` للشاشة، والعقود والترجمة والاختبارات والوثائق التابعة فقط. يكتب المنفذ قائمة الملفات الفعلية قبل التعديل؛ لا يفترض أن بنية مستقبلية موجودة. migrations تنشأ بأدوات MikroORM ضمن تهيئة المشروع الحالية وتوثق حدودها.

كل صف له مخرج واختبار رفض/فشل محدد. أضف اختبار النجاح المقابل، وAPI/Domain/DB حسب الخطر. اختبارات DB المطلوبة تعمل على PostgreSQL فعلي بدور التشغيل؛ لا SQLite أو mock بدل RLS أو أقفال. لكل أمر مغير تحقق من النطاق وIdempotency ونسخة المورد حيث يفرض العقد ذلك، مع Audit وOutbox عند أثر المجال. المصادقة والـCSRF والجلسة تطبق من المرحلة 3 على كل مسار لاحق.

قبل فصل دور التشغيل في P03-03، اختبارات P02 تثبت الدوام على PostgreSQL محلي synthetic فقط؛ لا توصف بأنها اختبارات عزل بدور إنتاجي. يعاد تشغيلها بالدور المحدود بعد P03-03. شرط دور التشغيل في الفقرة السابقة لا يفرض إنشاء هوية المرحلة 3 ضمن المرحلة 2.

القبول العام: نجاح فحوص الحزمة، ثم `pnpm check` عند تسليمها؛ اختبارات التكامل والأعطال المعنية؛ توثيق المهاجرات ومخاطر الرجوع؛ Computer Use للشاشات المنفذة؛ تحديث العقود والتتبع وسجل الأدلة والبصمات. لا يكفي اختبار تفاصيل دالة يكرر طريقة كتابتها. كل مهمة تحتفظ بحالتها غير المكتملة إن بقي قبول لازم غير منفذ.

P02-01 تسجل قدرات D-20 غير المثبتة كمتطلبات EX-01 محجوبة، وتضع أسئلة المزود واختبارات إثباتها مبكراً. لا تنتظر المرحلة 13 لاكتشاف أن حصرية القنوات أو دليل السحب غير ممثلين في العقد، ولا تختلق قدرة لدفع التنفيذ للأمام. لا يتضمن ذلك مراسلة المزود دون تفويض.

## سجل التبعيات المؤجلة الإلزامي

هذه التبعيات معروفة وليست إعفاءً من شرط أو بوابة. عند التنفيذ ينسخ المنفذ الصف المعني إلى سجل الحزمة مع حالته ودليله؛ لا يغلق الحزمة المستقبلة قبل معالجة ما يخصها.

| العقد المؤجل | الحزمة المنتجة | الحزمة التي تكمله | دليل الإغلاق |
|---|---|---|---|
| RLS ودور تشغيل على جداول القنوات | P02-03 | P03-03 | اختبارات حقيقية بنفس pool ودور لا يتجاوز RLS |
| مراجع Tenant والعضويات | P02-03 | P03-02/03 | FK/نطاق صحيح ورفض بيانات غير مملوكة |
| مراجع Property/Product/GrantProperty | P02-03 وP03-02 | P04-04 | قيود المالك وفحص orphans؛ لا نقل صامت للبيانات |
| مراجع RatePlan في Mapping | P02-03 وP04-04 | P05-01 | قيود فعلية للمنشأة والخطة وتفعيل مشروط باكتمال الربط |
| مراجع Reservation في Inbox/ExternalBookingLink | P02-03 | P06-01/04 | ربط فعلي بنفس النطاق واستثناء يحتفظ بعلاقة اختيارية صحيحة |
| إعادة تحقق تركيب مع التزامات مستقبلية | P04-03 | P05-03 وP06-06 | تغيير نسخة لا يعيد استهلاك موارد مثبتة |
| financial clearance للمغادرة | P07-03 | P08-06 | ذمة/تسوية فعلية وAT-R07، لا رد ثابت بالموافقة |
| استهلاك حدث المغادرة للتجهيز | P07-03 | P09-01 | مهمة واحدة لكل حدث وإعادة آمنة |

لا تضاف FKs إلى جدول مستقبلي غير موجود ولا ينشأ جدول أعمال شكلي لتسهيل migration. المهاجرات تطبق على قاعدة جديدة وأخرى تحتوي بيانات اصطناعية من المرحلة السابقة؛ أي سجل قديم غير صالح يوقف الترقية بتقرير آمن وخطة تصحيح محددة.
