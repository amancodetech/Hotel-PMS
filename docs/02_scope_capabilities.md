# نطاق المنتج ومصفوفة القدرات

حالة: نطاق V1 والتأجيلات محسومان في docs/23_v1_decisions.md وفق التفويض وسجل D؛ الجدول أدناه فهرس القدرات وليس إعلان تنفيذ.

القدرة متاحة حين تكون منفذة ومختبرة، ومسموحة بالاشتراك، ومهيأة للمنشأة، ومصرحاً للمستخدم بتنفيذها، ومسموحة بحالة المجال. تعطيلها لا يمحو تاريخ الالتزامات.

## أنواع المنشآت

سوق الإطلاق إندونيسيا مع العربية والإندونيسية والإنجليزية وIDR/USD وفق D-17. الصلاحيات المؤسسية وفق D-18 متطلب مشترك لجميع القدرات وليست إضافة مؤجلة أو مرتبطة بالمراسلات.

| النوع | نمط المورد | الحد التشغيلي اللازم لإعلان الدعم |
|---|---|---|
| فنادق وبوتيك وموتيلات | غرفة وجناح | دورة إقامة كاملة وتسوية وتدبير |
| منتجعات | غرف وفلل وأجنحة | مخزون مختلط؛ تحديد نطاق الباقات والأنشطة صراحة |
| فلل وشاليهات وبيوت عطلات | وحدة أو أجزاء | حصرية وتركيبات وتجهيز وتأمين عند الطلب |
| شقق مخدومة وفندقية | شقة واستوديو | مدد طويلة وفوترة دورية إذا كانت مطلوبة |
| نُزل وغرف مشتركة | سرير وغرفة | مخزون أسرة وتوافق وحجز حصرية |
| بيوت ضيافة | غرفة ومنزل | تدفق بسيط مع قدرات اختيارية |
| مخيمات وتخييم فاخر وأكواخ | موقع وخيمة وكوخ | فصل الموقع والمعدات والمرافق والموسمية |
| مجمعات مختلطة | عدة موارد | تفعيل عدة قدرات في Property واحدة |
| مجموعات فنادق | عدة Properties | صلاحيات وتقارير دون دمج غير مضبوط للمخزون |
| شركات الإدارة | وحدات لمُلّاك مختلفين | فصل المالك والمشغّل وحساب المستحقات عند الوعد به |

V1 معتمد بعد بوابات 0..13 وفق D-01؛ التفصيل الحاكم للقدرات والتأجيلات في docs/23_v1_decisions.md. أولوية D-16 هي CAP-13 مع منع التعارض لجميع موارد CAP-01/02/03. المرحلة 14 ليست التزاماً بتنفيذ كل التخصصات معاً؛ المراسلات مؤجلة إليها ولا ترتيب داخلي مفروض بينها وبين الحجز المباشر. المشتريات والمخزون العام والرواتب والولاء والذكاء الاصطناعي خارج V1 وتحتاج قرار نطاق مستقل.

«كل الأنواع» في D-16 تعني أنواع الموارد المعرفة في هذا الملف، لا الغرف والفلل فقط. يشمل ذلك مورد السرير والموقع والخيمة والكوخ والبيت والشقة، والعروض التي تحجز المورد كاملاً أو أجزاءه أو تركيباً منه. لا يعني الإدراج إعلان الدعم قبل اكتمال دورة الحجز واختبارات المخزون وMapping القناة لذلك النوع.
